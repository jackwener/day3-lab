## 1. 背景与问题

| 痛点 | 来源 |
|------|------|
| 现有系统为单一通用问答模式，无法满足研报解析、行情查询等专业化投研场景需求 | 用户反馈 |
| 研报阅读效率低：用户需手动阅读研报全文，无法快速提取评级、目标价、核心观点等关键信息 | 用户访谈 |
| 多份研报对比困难：不同券商对同一标的的观点差异需人工逐份比对，耗时且易遗漏 | 用户访谈 |
| 行情数据获取割裂：用户需切换至行情软件查询实时数据，无法在问答场景内直接获取 | 产品观察 |
| 专业分析门槛高：普通用户缺乏结构化投研分析框架，难以形成专业判断 | 用户行为数据 |

## 2. 提案概要

在现有投研问答助手基础上，于主界面右侧新增智能体面板（Agent Panel），提供 4 个系统内置智能体（研报解析、研报对比、实时行情、投资研究分析）和用户自定义智能体能力。内置智能体覆盖研报文件解析与结构化提取、多份研报多维对比、自然语言行情查询、专业投研分析师角色问答四大核心场景。用户自定义智能体为纯提示词模式，支持创建、编辑、删除、复制，数量上限为 20 个。所有智能体共享同一会话体系，支持会话内自由切换；未配置外部 API 时系统降级返回演示回复，保障基本可用性。

## 3. 范围边界

| 做（范围内） | 不做（范围外） |
|-------------|---------------|
| 右侧智能体面板：默认折叠图标栏，点击展开，分为“内置智能体”和“我的智能体”两个 Tab | 多租户隔离 / 企业级权限管理 |
| 研报解析智能体：上传单份研报（PDF/Word/HTML，≤50MB），结构化提取评级、目标价、核心观点等信息 | 批量研报自动抓取 / 外部研报源爬取 |
| 研报对比智能体：同时上传 2~5 份研报，生成评级、目标价、盈利预测、风险提示等多维对比 | 研报知识库长期沉淀与检索系统 |
| 实时行情智能体：将自然语言解析为 API 参数，查询个股、指数、板块、近 5 日走势等行情数据 | 自动下单 / 券商交易接口对接 |
| 投资研究分析智能体：以内置“资深投资研究分析师”角色输出专业分析与风险提示 | 组合优化算法 / 量化回测引擎 |
| 用户自定义智能体：基于提示词创建，支持编辑、删除、复制，数量上限 20 个 | 自定义智能体联网搜索 / 工具编排能力 |
| 研报上传交互：支持拖拽上传和点击上传，展示上传进度与文件缩略信息 | 微信、钉钉、飞书等 IM 平台集成 |
| 同一会话中切换不同智能体，保留对话历史并切换智能体上下文 | 积分体系 / 计费后台 |

## 4. 成功标准（可度量）

| 标准 | 度量方式 |
|------|----------|
| 主路径可走通 | 用户在 3 分钟内完成“展开智能体面板 → 选择智能体 → 提问/上传文件 → 查看结果”全链路 |
| 研报解析可验证 | 上传 1 份 PDF 研报后，系统在 5 秒内返回包含标题、评级、目标价、核心观点的结构化卡片 |
| 研报对比可验证 | 上传 2 份研报后，系统生成包含评级差异和目标价差异的对比表格 |
| 行情查询可验证 | 输入“贵州茅台今天的股价是多少”后，返回文字描述和数据卡片，含正确股票标识 |
| 自定义智能体可用 | 创建 1 个自定义智能体后，其出现在“我的智能体”分组中，并可正常参与对话 |
| 离线可用 | 未配置外部 LLM 或行情 API 时，系统返回演示回复或友好提示，而非报错页面 |

## 5. 风险（简表）

| 风险 | 影响 | 应对 |
|------|------|------|
| 外部 LLM 服务不可用 | 全部智能体问答能力降级 | 三级降级：主力 LLM → 备用模型 → Demo 模式兜底 |
| 外部行情 API 不可用或未配置 | 实时行情智能体无法返回真实数据 | 通过环境变量控制启用状态，未配置时返回 Demo 行情数据 |
| 研报文件格式解析失败 | 研报解析与对比结果不完整 | 明确支持格式范围，后端捕获异常并返回可读错误提示 |
| 自定义提示词滥用或注入 | 智能体行为异常、输出失控 | 限制提示词长度（≤5000 字符），增加敏感词与基础安全校验 |

## 6. 立项前置条件（Go / No-Go）

- ☐ 现有投研问答助手后端可正常启动，会话管理接口可用
- ☐ 前端 React 项目可独立启动并正确代理 API 请求
- ☐ 至少 1 个 LLM 接口（或 Demo 模式）可返回有效响应
- ☐ 外部行情 API 已申请完成或具备 Demo 数据方案
- ☐ 演示用研报文件（≥2 份 PDF）已准备
- ☐ 自定义智能体的图标与表单约束已确认
