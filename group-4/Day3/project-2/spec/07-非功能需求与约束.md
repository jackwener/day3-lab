## 1. 性能需求

### 1.1 SLO 指标

| 指标 | 目标值 | 度量方式 | 说明 |
|------|--------|----------|------|
| 首屏加载时间 | < 3s | Lighthouse | 从输入 URL 到首屏渲染完成 |
| 可交互时间 (TTI) | < 3.5s | Lighthouse | 页面可响应用户操作 |
| 动画帧率 | ≥ 30fps | Chrome DevTools | 仪式动画和卡牌翻转 |
| 交互响应延迟 | < 100ms | 手动测试 | 点击到视觉反馈 |
| 页面切换时间 | < 500ms | 手动测试 | 状态切换动画时长 |
| 内存占用 | < 100MB | Chrome DevTools | 单标签页峰值 |

### 1.2 降级策略

| 场景 | 降级方案 | 触发条件 |
|------|----------|----------|
| 动画性能不足 | 2D 翻转替代 3D | FPS < 20 持续 3 秒 |
| 粒子效果卡顿 | 减少粒子数量 50% | FPS < 25 |
| 低端设备 | 禁用复杂阴影/发光 | 检测 GPU 等级 |
| 用户偏好 | 减少动画 | prefers-reduced-motion: reduce |
| 网络缓慢 | 骨架屏占位 | 资源加载 > 2s |

## 2. 安全需求

| 类别 | 当前实现 | 未来规划 |
|------|----------|----------|
| 认证 | 无（纯前端应用） | 保持无认证 |
| 授权 | 无 | 保持无授权 |
| 数据存储 | localStorage（非敏感数据） | 保持本地存储 |
| XSS 防护 | React 默认转义 | 保持 |
| CSRF 防护 | 无后端接口，不涉及 | 保持 |
| 内容安全 | 内联样式/脚本，无外部资源 | 可考虑 CSP |

## 4. 约束底线

| 约束类型 | 约束内容 |
|----------|----------|
| 时间约束 | 开发时间 ≤ 2 小时 |
| 技术约束 | 纯前端实现，无后端依赖 |
| 规模约束 | 单页面应用，无路由跳转 |
| 依赖约束 | 核心功能零外部库（可选 Three.js） |
| 存储约束 | 仅使用 localStorage，无服务端存储 |
| 网络约束 | 离线可用，无需网络连接 |
| 构建约束 | 支持静态部署（Vite 构建） |

## 5. 输入约束

| 字段 | 约束 | 说明 |
|------|------|------|
| 暖场测试答案 | 每题必选 | 5 道选择题 |
| 抽卡选择 | 阶段限制 | 必须按顺序选择 3 张 |
| 再来一次确认 | 无 | 直接重置，无需确认 |
| localStorage | 5MB 限制 | 图册最多保存 20 条记录 |

## 6. 错误码体系

| error.code | 触发条件 | 用户提示 |
|------------|----------|----------|
| STORAGE_FULL | localStorage 空间不足 | 自动清理旧记录 |
| ANIMATION_ERROR | CSS 动画执行异常 | 降级显示 |
| STATE_INVALID | 状态机异常 | 重置到初始状态 |
| RENDER_ERROR | React 渲染异常 | 显示错误页，提供刷新按钮 |
