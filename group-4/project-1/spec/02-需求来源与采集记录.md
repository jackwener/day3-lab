### S-02 用户访谈：投研分析师

| 字段 | 内容 |
|------|------|
| 来源类型 | 用户访谈 |
| 时间 | 2026-04-14 |
| 受访角色 | 投研分析师（3 人） |
| 关键诉求 | ① 每天阅读研报 5~10 份，手动提取评级、目标价耗时约 2 小时，希望自动化；② 跨券商研报观点对比依赖 Excel 手工整理，容易遗漏关键差异；③ 查行情需切换到行情软件，打断分析流程；④ 不同分析场景需要不同 AI 角色，希望能自定义 |
| 痛点量化 | 研报阅读耗时占工作日 30%，行情查询中断频率 ≥10 次/天 |
| 对应需求 | → `04` SC-02（研报解析）、SC-03（研报对比）、SC-04（实时行情）、SC-06（自定义智能体） |
