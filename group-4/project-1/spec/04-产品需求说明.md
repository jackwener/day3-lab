> **04 的定位**：`03` 说了"为什么做"，04 翻译成"做什么、不做什么、多重要"。`05` 再拆成用户故事和验收标准。

## 1. 愿景与目标

| 03 痛点 | 04 目标 |
|---------|---------|
| 单一通用问答无法满足专业化投研场景 | 提供 4 个内置专业智能体 + 用户自定义智能体，覆盖投研全链路 |
| 研报阅读效率低，手动提取关键信息 | 研报解析智能体：上传即提取评级、目标价、核心观点、财务预测，卡片展示 |
| 多份研报对比困难，需手动整理到 Excel | 研报对比智能体：上传 2~5 份自动生成多维对比表格 |
| 行情数据获取割裂，需切换至行情软件 | 实时行情智能体：自然语言查询 → 新浪财经 API → 数据卡片 |
| 专业分析门槛高，缺乏结构化框架 | 投资研究分析智能体：内置 15 年经验投研分析师角色，框架化输出 |
| 不同场景需要不同专家角色 | 用户自定义提示词智能体：灵活创建个性化 AI 角色 |

## 2. 目标用户

| 角色 | 使用目标 | 频率 |
|------|----------|------|
| 投研分析师 | 快速解析研报、对比多份研报、查询行情、获取专业分析 | 每天多次 |
| 基金经理 | 通过自定义智能体获取定制化投资分析建议 | 每天数次 |
| 研究助理 | 上传研报提取关键信息，辅助整理投研素材 | 每天多次 |

## 3. 核心业务场景

| 编号 | 场景名 | 用户路径（对齐代码实现） |
|------|--------|--------------------------|
| SC-01 | 智能体选择与切换 | 主界面展示智能体网格卡片（`agentTab` 切换内置/我的）→ 点击卡片 → `activeAgent` 更新 → header 显示当前智能体标识 → 进入对话模式 |
| SC-02 | 研报解析 | 选择"研报解析"→ 拖拽/点击上传 1 份 PDF（≤50MB）→ `POST /parse-report` → 后端 `report_parser.parse_single()` 调用 LLM 提取 → 前端渲染 `ParseCard`（标题、机构、评级、目标价、财务预测、风险） |
| SC-03 | 研报对比 | 选择"研报对比"→ 上传 2~5 份研报 → `POST /compare-reports` → 后端 `report_parser.compare_reports()` → 前端渲染 `CompareCard`（对比表格 + 差异总结 + 最乐观/最悲观机构） |
| SC-04 | 实时行情查询 | 选择"实时行情"→ 输入"贵州茅台今天股价"→ `GET /market-data?query=...` → 后端 `market_data.fetch_market_data()` 解析股票代码 → 调用新浪财经 API → 前端渲染 `MarketRecord` 卡片 |
| SC-05 | 投资研究分析 | 选择"投研分析"→ 输入分析问题 → `POST /ask` 携带内置 system_prompt → agent.py 三级降级调用 → 返回专业框架化分析 |
| SC-06 | 创建自定义智能体 | 点击"创建智能体"→ 弹出 Modal → 填写名称/描述/图标(18 个 Emoji 预设)/提示词 → `POST /custom-agents` → 出现在"我的智能体"Tab |
| SC-07 | 会话管理 | Sidebar 展示会话列表 → 点击"新建会话" → `POST /sessions` → 选中后加载记录 → 输入区发送消息 → 首次提问自动重命名会话标题（query 前 20 字符） |

## 4. 产品规则

| 编号 | 规则 | 代码实现位置 |
|------|------|-------------|
| R-01 | 每条提问 **MUST** 绑定 `session_id`，会话必须存在且 `status=active` | `agent_bp.py` — ask 端点校验 |
| R-02 | `query` 长度 1～500 字符，为空返回 `EMPTY_QUERY`，超长返回 `INVALID_QUERY` | `agent_bp.py` — 参数校验 |
| R-03 | 研报上传 **MUST** 校验文件格式（PDF/Word/HTML）和大小（≤50MB） | `agent_bp.py` — parse-report 端点 |
| R-04 | 研报对比 **MUST** 上传 2~5 份文件 | `agent_bp.py` — compare-reports 端点 |
| R-05 | 实时行情未配置或接口不可用时 **MUST** 返回 Demo 数据（`demo=true`） | `market_data.py` — fetch_market_data() |
| R-06 | 自定义智能体名称 ≤20 字符，提示词 ≤5000 字符，描述 ≤200 字符 | `agent_bp.py` — custom-agents 端点 |
| R-07 | 所有回答 **MUST** 携带 `answer_source`（copaw/bailian/demo）、`llm_used`、`response_time_ms` | `agent.py` — ask() 返回值 |
| R-08 | 投资研究分析智能体回答末尾 **MUST** 附带风险提示和免责声明 | 前端 system_prompt 内置 |
| R-09 | 会话删除为**软删除**（`status='deleted'`），已删除会话不可再提交问答 | `storage.py` — delete_session() |
| R-10 | 首次问答时会话标题自动更新为 query 前 20 字符 + "..." | `storage.py` — add_record() |

## 5. 能力与优先级

| 子能力 | 优先级 | 对应场景 |
|--------|--------|----------|
| 会话管理（CRUD + 软删除 + 自动命名） | **P0** | SC-07 |
| 三级降级问答（CoPaw → 百炼 → Demo） | **P0** | SC-05 |
| 智能体面板（网格卡片 + Tab 切换） | **P0** | SC-01 |
| 研报解析（PDF/Word/HTML → 结构化卡片） | **P0** | SC-02 |
| 研报对比（2~5 份 → 对比表格） | **P0** | SC-03 |
| 实时行情查询（新浪财经 API + Demo 降级） | **P0** | SC-04 |
| 自定义智能体 CRUD（创建/编辑/删除） | **P1** | SC-06 |
| 能力探测接口（CoPaw/百炼配置状态） | **P1** | SC-07 |
| 文件上传交互（拖拽 + 点击 + 进度） | **P0** | SC-02, SC-03 |
| 离线 Demo 模式（全链路降级兜底） | **P0** | 全场景 |

## 6. 验收与成功标准（PRD 层）

| 标准 | 度量 |
|------|------|
| 可演示 | 选择智能体 → 发起对话 → 收到回答，**3 分钟内**演示完毕 |
| 研报解析可验证 | 上传 1 份 PDF 研报后返回含标题、机构、评级、目标价、财务预测的 ParseCard |
| 研报对比可验证 | 上传 2 份研报后生成 CompareCard，含各家评级/目标价差异 + 最乐观/最悲观机构 |
| 行情查询可验证 | 输入"贵州茅台"后返回 MarketRecord 卡片，含股票代码、价格、涨跌幅 |
| 自定义智能体可用 | 创建 1 个自定义智能体后出现在"我的智能体"Tab，可正常对话 |
| 离线可用 | 不配置 DASHSCOPE_API_KEY 和 IRA_COPAW_ASK_URL 时，`answer_source=demo`，不报错 |
| Swagger 可访问 | `http://localhost:5003/api/v1/swagger` 正常展示全部端点文档 |
