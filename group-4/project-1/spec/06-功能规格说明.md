## 1. 页面总体布局（对齐 App.jsx）

```
┌──────────────────────────────────────────────────────────┐
│  header: 标题"投研问答助手" + 当前智能体标识芯片 + 能力状态  │
├──────────────┬───────────────────────────────────────────┤
│  sidebar     │  main-content（三态渲染）                   │
│  会话列表     │  A) 空状态（无会话 → "选择或创建会话"提示）   │
│  [+新建会话]  │  B) 欢迎态（有会话无记录 → 2×2 常见问题卡片）│
│  session1    │  C) 对话态（有记录 → QARecord 列表）        │
│  session2    │                                            │
│              │  ┌──────────────────────────────────┐      │
│              │  │ 智能体面板（右侧可折叠 panelOpen） │      │
│              │  │ Tab: 内置智能体 | 我的智能体        │      │
│              │  │ 网格卡片 + 创建按钮               │      │
│              │  └──────────────────────────────────┘      │
│              │  input-area: ChatInput 组件                 │
└──────────────┴───────────────────────────────────────────┘
```

## 2. 智能体面板（对齐 US-007）

### 2.1 布局与 Tab 切换

- 面板通过 `panelOpen` 状态控制展开/折叠
- 分两个 Tab（`agentTab` 状态）：「内置智能体」和「我的智能体」

### 2.2 内置智能体卡片（2×2 网格）

| 图标 | 名称 | 描述 | activeAgent ID |
|------|------|------|---------------|
| 📄 FileText | 研报解析 | 上传研报，自动提取评级、目标价等关键信息 | `report-parse` |
| 📊 BarChart3 | 研报对比 | 上传多份研报，自动生成多维度对比表格 | `report-compare` |
| 📈 TrendingUp | 实时行情 | 自然语言查询行情，返回实时数据卡片 | `market-data` |
| 🔬 Microscope | 投研分析 | 15 年经验投研分析师，框架化分析输出 | `research` |

### 2.3 我的智能体区

- 展示 `customAgents` 数组中的智能体卡片
- 右上角「+ 创建智能体」按钮
- 支持编辑、删除操作

### 2.4 卡片交互

| 操作 | 行为 |
|------|------|
| 单击卡片 | `activeAgent` 更新 → header 显示智能体名称 → 对话模式切换上下文 |
| 点击编辑 | 打开 Modal 弹窗，加载当前智能体数据到表单 |
| 点击删除 | 确认后 `DELETE /custom-agents/<id>` |

## 3. 创建/编辑智能体 Modal（对齐 US-006）

| 字段 | 类型 | 必填 | 约束 | 说明 |
|------|------|------|------|------|
| name | text | 是 | ≤ 20 字符 | 智能体显示名 |
| description | textarea | 否 | ≤ 200 字符 | 卡片描述 |
| icon | emoji-picker | 否 | 18 个预设 Emoji | 默认 🤖 |
| system_prompt | textarea | 是 | ≤ 5000 字符 | 定义角色和风格，含实时字数统计 |

- `formErr` 状态管理校验错误
- 保存后自动刷新 `customAgents` 列表

## 4. 文件上传区（对齐 US-003, US-004）

> 仅在 `activeAgent` 为 report-parse 或 report-compare 时显示。

| 元素 | 行为 |
|------|------|
| 拖拽区域 | `isDrag` 状态控制，虚线边框，hover 时高亮 |
| 点击上传按钮 | 触发文件选择器，允许 PDF/Word/HTML |
| 文件列表 | `uploadedFiles` 状态，显示文件名 + 删除按钮 |
| 提交按钮 | 研报解析："开始解析研报" / 研报对比："开始对比分析" |

**研报解析**：限制 1 份文件，≤ 50MB
**研报对比**：限制 2~5 份文件，每份 ≤ 50MB

## 5. 对话区组件

### 5.1 ParseCard（研报解析结构化卡片）

```
┌─────────────────────────────────────┐
│ 📄 标题: XXX研报                     │
│ 机构: XXX证券  |  评级: 买入          │
│ 目标价: ¥1888                       │
├─────────────────────────────────────┤
│ 财务预测:                            │
│ 24E营收增速: 15% | 25E营收增速: 12%   │
│ 24E净利润: 50亿 | PE: 25x            │
├─────────────────────────────────────┤
│ 风险提示:                            │
│ • 风险1  • 风险2  • 风险3            │
└─────────────────────────────────────┘
```

### 5.2 CompareCard（研报对比表格）

- 表格展示各家券商 rating + target_price
- 下方文字总结：rating_summary、price_summary
- 标识 most_bullish / most_bearish 机构

### 5.3 MarketRecord（行情数据卡片）

```
┌─────────────────────────────────────┐
│ 📈 贵州茅台 (600519)                 │
│ ¥1,856.00  ▲ +2.35%  +42.60        │
│ 成交量: 3.2万手  |  成交额: 59.4亿   │
│ 今开: 1,820.00  |  昨收: 1,813.40   │
│ 最高: 1,862.00  |  最低: 1,815.00   │
└─────────────────────────────────────┘
```

涨跌颜色：涨 → 红色，跌 → 绿色。Demo 数据显示警告提示。

### 5.4 QARecord（普通问答卡片）

- 用户提问（右侧气泡）+ AI 回答（左侧气泡）
- `SourceBadge`：显示 answer_source（copaw/bailian/demo）+ response_time_ms
- `cited_passages` 引用折叠区

## 6. ChatInput 子组件（性能优化）

> 独立子组件，`memo` + `useImperativeHandle` 隔离输入状态，避免全局重渲染。

| 元素 | 行为 |
|------|------|
| textarea | 最多 500 字，超长显示红色警告 + 字数统计 |
| 发送按钮 | `isSubmitting` 时 disabled + 旋转动画"发送中…" |
| 快捷键 | Enter 发送，Shift+Enter 换行 |
| 文件按钮 | 研报智能体时可见，触发文件上传 |

## 7. 三态渲染

| 状态 | 条件 | 展示 |
|------|------|------|
| 空状态 | `curSession === null` | "选择或创建会话"提示 + 新建快捷按钮 |
| 欢迎态 | 有会话但 `records.length === 0` | 2×2 常见问题网格（4 条预设问题） |
| 对话态 | `records.length > 0` | 按 created_at 正序的 QARecord 列表，自动滚动到底部 |

## 8. 错误处理（对齐 agent_bp.py 错误码）

| 后端 error.code | HTTP | 前端展示 |
|-----------------|------|----------|
| `EMPTY_QUERY` | 400 | toast 底部中央："请输入问题" |
| `INVALID_QUERY` | 400 | 输入区红色警告 + 字数统计 |
| `SESSION_NOT_FOUND` | 404 | toast："会话不存在或已删除" |
| `MISSING_FIELD` | 400 | toast："缺少必填字段" |
| `LLM_UNAVAILABLE` | 500 | toast 后降级显示 Demo 回复 |
| 网络错误 | — | toast："网络错误，请重试"，输入内容保留 |

## 9. 状态管理（App.jsx 顶层状态）

| State 变量 | 类型 | 初始值 | 用途 |
|------------|------|--------|------|
| `sessions` | Session[] | [] | 会话列表 |
| `curSession` | Session\|null | null | 当前选中会话 |
| `records` | QARecord[] | [] | 当前会话问答记录 |
| `isSubmitting` | boolean | false | 请求中状态 |
| `caps` | object | {} | 系统能力状态 |
| `error` | string\|null | null | 全局错误消息 |
| `panelOpen` | boolean | false | 智能体面板展开 |
| `agentTab` | string | 'builtin' | 智能体 Tab |
| `activeAgent` | object\|null | null | 当前选中智能体 |
| `customAgents` | Agent[] | [] | 自定义智能体列表 |
| `showModal` | boolean | false | 创建/编辑弹窗 |
| `uploadedFiles` | File[] | [] | 待上传文件 |
| `isDrag` | boolean | false | 拖拽状态 |
| `reportCtx` | object\|null | null | 研报上下文（用于追问） |
