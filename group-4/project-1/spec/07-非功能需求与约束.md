## 1. 性能需求

### 1.1 延迟 SLO

| 指标 | 目标值 | 代码实现 |
|------|--------|----------|
| **问答端点 P95 延迟** | < **4500ms**（单级 LLM 超时） | `copaw_bridge.py` timeout=4500ms · `bailian_qa.py` timeout=4500ms |
| **会话管理端点延迟** | < 100ms | `storage.py` JSON 读写（列表接口） |
| **行情查询端点延迟** | < 3000ms | `market_data.py` 新浪 API 调用 |
| **研报解析端点延迟** | < 10000ms（含文件解析 + LLM） | `report_parser.py` extract_text + LLM 调用 |
| **文件上传延迟** | < 2000ms（不含解析） | 50MB 上限 |

### 1.2 三级降级策略（对齐 agent.py）

```
agent.ask(query, session_id, system_prompt=None, context=None)
  ├─[1] CoPaw HTTP桥  → answer_source='copaw',   llm_used=True
  ├─[2] 百炼 DashScope → answer_source='bailian', llm_used=True
  └─[3] Demo 兜底      → answer_source='demo',    llm_used=False
```

| 约束 | 说明 |
|------|------|
| 三级降级**不可跳级** | 必须按 CoPaw → 百炼 → Demo 顺序尝试 |
| 降级**静默执行** | 失败时 WARNING 日志，不抛异常，通过 answer_source 标识 |
| Demo 模式**始终可用** | 无外部依赖，纯字符串拼接 |
| CoPaw 超时 | 4500ms，HTTP POST 调用 |
| 百炼超时 | 4500ms，DashScope API 调用 |
| 行情 API 降级 | 新浪接口不可用时返回 Demo 行情数据（`demo=true`） |
| 研报解析降级 | LLM 不可用时返回 Demo 解析数据 |

## 2. 可用性需求

| 指标 | 目标值 | 说明 |
|------|--------|------|
| 服务可用性 | **99%**（教学环境） | 单实例部署 |
| MTTR | < 5 分钟 | start.sh 一键重启 |
| JSON 损坏恢复 | 自动返回空数组 | `storage.py` 读取异常时 ERROR 日志 + 空数据兜底 |

## 3. 可观测性需求

### 3.1 链路追踪

| 项 | 规格 |
|----|------|
| traceId 格式 | `tr_{uuid.hex[:16]}`（16 位十六进制） |
| 注入位置 | 所有成功响应顶层 + 错误响应 `error.traceId` |
| 生成方式 | 每次请求在 Route 层生成 |

### 3.2 错误码体系（对齐 agent_bp.py）

| HTTP | error.code | 触发条件 |
|------|------------|----------|
| 400 | `EMPTY_QUERY` | query 为空/空白/null |
| 400 | `INVALID_QUERY` | query > 500 字符 |
| 400 | `MISSING_FIELD` | 缺少必填字段 |
| 404 | `SESSION_NOT_FOUND` | 会话不存在或 status=deleted |
| 500 | `UPSTREAM_ERROR` | Agent 编排内部异常 |

## 4. 安全需求

| 项 | 当前实现 | 说明 |
|----|----------|------|
| API 认证 | 无（开放访问） | Workshop 教学版 |
| CORS | flask-cors 全开放 | 生产需白名单 |
| 速率限制 | 无 | 教学场景不限速 |

### 4.1 敏感数据保护

| 数据类型 | 保护方式 |
|----------|----------|
| DASHSCOPE_API_KEY | `.env` 环境变量，`.gitignore` 排除 |
| IRA_COPAW_*_URL | `.env` 环境变量 |
| 上传研报文件 | 仅存内存处理，不持久化到磁盘 |
| 问答记录 | 本地 JSON 文件，LLM 调用时传输 |

## 5. 数据约束（对齐 agent_bp.py Marshmallow Schema）

| 约束 | 规格 | 来源 |
|------|------|------|
| `query` 最大长度 | 500 字符 | Schema 校验 |
| `session_id` 必填 | 非空字符串，会话需 active | ask 端点 |
| `title` 最大长度 | 100 字符 | sessions 端点 |
| 研报文件格式 | PDF / Word / HTML | parse-report |
| 研报文件大小 | ≤ 50MB | parse-report |
| 研报对比文件数 | 2~5 份 | compare-reports |
| 智能体名称 | ≤ 20 字符 | custom-agents |
| 智能体描述 | ≤ 200 字符 | custom-agents |
| 智能体提示词 | ≤ 5000 字符 | custom-agents |
| 智能体图标 | ≤ 10 字符（Emoji） | custom-agents |

### 5.1 类型约束

| 字段 | 类型 | 约束 |
|------|------|------|
| `llm_used` | boolean | 必须为 True/False |
| `answer_source` | string | 枚举：copaw \| bailian \| demo |
| `status` | string | 枚举：active \| deleted |
