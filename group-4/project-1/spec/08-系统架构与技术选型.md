## 1. 架构总览

### 1.1 系统上下文（对齐实际代码）

```

│         Tailwind CSS + lucide-react               │

                    │ HTTP /api/v1/agent/*
                    │ (Vite proxy → localhost:5003)
                    ▼
┌──────────────────────────────────────────────────┐

│  http://localhost:5003                            │
│  ┌─────────────────────────────────────────────┐ │
│  │  agent_bp.py — 10 个 API 端点               │ │

│  └──────┬──────────┬──────────┬────────────────┘ │
│         ▼          ▼          ▼                   │
```

### 1.2 架构风格

| 决策 | 选型 | 理由 |
|------|------|------|
| **前后端分离** | React SPA + Flask REST API | 独立开发/部署，教学清晰 |
| **单体部署** | 前后端各一个进程 | 不引入微服务复杂度 |
| **分层架构** | Route(agent_bp) → Agent(agent.py) → Provider/Storage | 各层职责清晰，可独立替换 |
| **单例存储** | Storage 类单例模式 | JSON 文件无并发写入需求 |

## 2. 后端分层结构（对齐实际文件）

| 层 | 文件 | 允许做 | 禁止做 |
|----|------|--------|--------|
| **Route** | `blueprints/agent_bp.py` | 参数校验(Marshmallow)、HTTP 状态码、traceId、Swagger 文档 | 直接读写文件、调用 LLM |
| **Agent 编排** | `agent.py` | 三级降级编排、结果组装、system_prompt 注入 | 感知 HTTP 请求/响应 |
| **CoPaw Provider** | `copaw_bridge.py` | HTTP POST 调用 CoPaw API、超时 4500ms | 操作本地存储 |
| **百炼 Provider** | `bailian_qa.py` | DashScope API 调用、超时 4500ms、错误分类 | 操作本地存储 |
| **研报解析** | `report_parser.py` | PDF/Word/HTML 文本提取、LLM 结构化解析、Demo 兜底 | 直接响应 HTTP |
| **行情代理** | `market_data.py` | 新浪财经接口调用、股票代码解析(58个别名)、Demo 兜底 | 操作本地存储 |
| **Storage** | `storage.py` | JSON CRUD、软删除、自动命名、数据校验 | 调用外部 API |

## 3. 前端架构（对齐 App.jsx）

| 项 | 选型 | 理由 |
|----|------|------|
| UI 框架 | React 18（Hooks） | 教学通用性最高 |
| 构建工具 | Vite 5 | 极快 HMR |
| 样式方案 | Tailwind CSS 4 | 原子化 CSS，快速迭代 |
| 图标库 | lucide-react（43 个图标） | 轻量、一致性好 |
| HTTP 客户端 | `fetch` API 封装（`api.js`） | 浏览器原生 |
| 状态管理 | `useState` + `useEffect`（14 个状态变量） | 够用，不引入 Redux |
| 性能优化 | `memo` + `useImperativeHandle` + `useCallback` | ChatInput 隔离，8 个纯展示组件 memo 包装 |

## 4. 三级降级编排（对齐 agent.py）

```
ask(query, session_id, system_prompt, context)
  ├─[1] CoPaw     → {source:"copaw",   llm:true,  model:"copaw"}
  ├─[2] 百炼      → {source:"bailian", llm:true,  model:"qwen-turbo"}
  └─[3] Demo      → {source:"demo",    llm:false, model:null}
```

| 提供商 | 文件 | 配置检测 | 超时 | 错误处理 |
|--------|------|----------|------|----------|
| **CoPaw** | `copaw_bridge.py` | `IRA_COPAW_ASK_URL` 非空 | 4500ms | 返回 None → WARNING → 降级 |
| **百炼** | `bailian_qa.py` | `DASHSCOPE_API_KEY` 非空 | 4500ms | AuthError/RateLimit/Timeout → WARNING → 降级 |
| **Demo** | `agent.py` | 始终可用 | 0ms | 纯字符串拼接 |

## 5. 数据存储架构（对齐 storage.py）

| 文件 | 内容 | 读写模式 |
|------|------|----------|
| `data/sessions.json` | 会话列表 | RMW 全量读写 |
| `data/qa_records.json` | 问答记录 | RMW 全量读写 |
| `data/custom_agents.json` | 自定义智能体 | RMW 全量读写 |

- 编码 UTF-8，缩进 2 空格
- 单例模式（`_instance`），全局单一实例
- JSON 损坏时自动返回空数组 + ERROR 日志

## 7. ADR（架构决策记录）

| ADR | 决策 | 核心理由 |
|-----|------|----------|
| ADR-001 | Flask 而非 FastAPI | 学习曲线低，不需 async/await |
| ADR-002 | JSON 文件而非 SQLite | 零依赖启动，教学门槛最低 |
| ADR-003 | React 而非 Vue3 | 生态成熟，教学通用性最高 |
| ADR-004 | Tailwind CSS 而非 CSS-in-JS | 原子化开发快，无运行时开销 |
| ADR-005 | flask-smorest 而非手写文档 | 自动生成 Swagger，Schema 即文档 |
| ADR-006 | 新浪财经而非付费行情 API | 免费可用，教学场景足够 |
| ADR-007 | 软删除而非硬删除 | 保留数据可恢复性，防误操作 |
