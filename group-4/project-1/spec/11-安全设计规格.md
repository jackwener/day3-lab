## 1. 安全目标与定位

> 本模块为 **Workshop 教学版**，安全设计聚焦于教学演示场景下的基本防护，不涉及生产级安全体系。

| 安全目标 | 说明 | 当前实现 |
|----------|------|----------|
| 密钥不泄露 | API Key 等敏感信息不出现在代码仓库中 | `.env` 文件 + `.gitignore` 排除 |
| 输入可控 | 用户输入经过类型和长度校验 | Marshmallow Schema 白名单校验 |
| 数据不出域 | 研报文件仅在内存中处理，不持久化到磁盘 | `report_parser.py` 内存解析 |
| 错误不泄内 | 异常信息不暴露内部栈信息 | 统一错误响应格式 + error.code |

## 2. 认证与授权

| 项 | 当前状态 | 说明 |
|----|----------|------|
| API 认证 | **无**（开放访问） | Workshop 教学版，单机运行 |
| 用户鉴权 | **无** | 无多用户概念 |
| CORS 策略 | flask-cors **全开放** | `CORS(app)` 默认配置 |
| 速率限制 | **无** | 教学场景不限速 |

> **生产化建议**：接入 JWT 令牌认证、CORS 白名单、API Gateway 限速。

## 3. 敏感数据保护

### 3.1 数据分级

| 级别 | 数据类型 | 存储位置 | 保护措施 |
|------|----------|----------|----------|
| **L3-机密** | `DASHSCOPE_API_KEY` | `.env` 文件 | `.gitignore` 排除，仅环境变量注入 |
| **L3-机密** | `IRA_COPAW_ASK_URL` / `IRA_COPAW_CAPS_URL` | `.env` 文件 | 同上 |
| **L2-内部** | 用户上传的研报文件 | **仅内存** | 处理后不持久化，`report_parser.py` 全流程内存操作 |
| **L2-内部** | 问答记录（query/answer） | `data/qa_records.json` | 本地文件系统 |
| **L1-一般** | 会话元数据（title/created_at） | `data/sessions.json` | 本地文件系统 |
| **L1-一般** | 自定义智能体配置 | `data/custom_agents.json` | 本地文件系统 |

### 3.2 密钥管理

| 密钥 | 管理方式 | 代码位置 |
|------|----------|----------|
| `DASHSCOPE_API_KEY` | `.env` → `python-dotenv` 加载 → `os.environ.get()` | `bailian_qa.py` |
| `IRA_COPAW_ASK_URL` | `.env` → `os.environ.get()` | `copaw_bridge.py` |
| `IRA_COPAW_CAPS_URL` | `.env` → `os.environ.get()` | `agent_bp.py` capabilities |
| `DASHSCOPE_MODEL` | `.env` → `os.environ.get()` 默认 `qwen-turbo` | `bailian_qa.py` |

**禁止事项**：
- 禁止在代码中硬编码 API Key
- `.env` 文件不得提交到 Git 仓库
- `.env.example` 仅包含键名和注释，不含实际值

## 4. 输入校验（对齐 agent_bp.py Marshmallow Schema）

| 端点 | 字段 | 校验规则 | 失败响应 |
|------|------|----------|----------|
| POST /ask | `query` | 非空/非纯空白 | 400 `EMPTY_QUERY` |
| POST /ask | `query` | ≤ 500 字符 | 400 `INVALID_QUERY` |
| POST /ask | `session_id` | 非空 + 会话 active | 404 `SESSION_NOT_FOUND` |
| POST /sessions | `title` | ≤ 100 字符 | 400 `MISSING_FIELD` |
| POST /parse-report | `file` | 格式 PDF/Word/HTML | 400 错误提示 |
| POST /parse-report | `file` | ≤ 50MB | 400 错误提示 |
| POST /compare-reports | `files` | 2~5 份 | 400 错误提示 |
| POST /custom-agents | `name` | 非空，≤ 20 字符 | 400 `MISSING_FIELD` |
| POST /custom-agents | `system_prompt` | 非空，≤ 5000 字符 | 400 `MISSING_FIELD` |
| POST /custom-agents | `description` | ≤ 200 字符 | 400 `MISSING_FIELD` |
| POST /custom-agents | `icon` | ≤ 10 字符 | 400 `MISSING_FIELD` |

## 5. LLM 调用安全

### 5.1 提示词注入防护

| 措施 | 实现 |
|------|------|
| 提示词长度限制 | system_prompt ≤ 5000 字符 |
| 上下文截断 | context 传入 LLM 前截取前 3000 字符（`agent.py`） |
| 角色固定 | 百炼调用使用 `messages` 格式，system role 不可被用户覆盖 |

### 5.2 外部调用安全

| 外部服务 | 安全措施 |
|----------|----------|
| CoPaw API | HTTPS 调用，超时 4500ms，异常捕获 + 降级 |
| 百炼 DashScope | Bearer Token 认证，超时 4500ms，AuthError 分类处理 |
| 新浪财经 | HTTP 调用，超时控制，返回数据校验 |

## 6. 文件上传安全

| 检查项 | 实现方式 |
|--------|----------|
| 文件格式白名单 | 仅允许 PDF / Word / HTML（按扩展名和 MIME 类型） |
| 文件大小限制 | 单文件 ≤ 50MB |
| 文件数量限制 | 研报对比 2~5 份 |
| 内存处理 | 文件仅在内存中解析，不写入磁盘 |
| 异常处理 | 解析失败返回可读错误提示，不暴露内部异常 |

## 7. 错误处理安全

| 原则 | 实现 |
|------|------|
| 统一错误格式 | `{ error: { code, message, details, traceId } }` |
| 不泄露内部信息 | error.message 为用户可读文本，不含栈信息 |
| traceId 可追溯 | 每个错误响应携带 traceId，便于日志定位 |
| 降级不中断 | LLM 异常 → WARNING 日志 → 静默降级，用户无感知 |

## 8. STRIDE 威胁清单

| 威胁 | 风险等级 | 当前状态 | 缓解措施 |
|------|----------|----------|----------|
| **S** 欺骗（Spoofing） | 低 | 无认证 | 教学版可接受；生产需加 JWT |
| **T** 篡改（Tampering） | 低 | JSON 文件无加密 | 教学版可接受；生产需加文件完整性校验 |
| **R** 否认（Repudiation） | 低 | traceId 链路追踪 | traceId + 日志 |
| **I** 信息泄露（Info Disclosure） | 中 | API Key 在 .env | .gitignore 排除 + 错误不泄内 |
| **D** 拒绝服务（DoS） | 低 | 无速率限制 | 教学版可接受；生产需加限速 |
| **E** 权限提升（Elevation） | 低 | 无权限体系 | 教学版可接受；生产需加 RBAC |

## 9. 安全检查清单

- [ ] `.env` 文件已加入 `.gitignore`
- [ ] `.env.example` 不含实际 API Key 值
- [ ] 所有用户输入经过 Marshmallow Schema 校验
- [ ] 文件上传有格式白名单和大小限制
- [ ] 研报文件不持久化到磁盘
- [ ] 错误响应不暴露内部栈信息
- [ ] LLM 调用有超时控制（4500ms）
- [ ] 降级链异常静默处理，不中断服务
