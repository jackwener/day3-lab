## 4. 风险与应对

| 风险 | 影响 | 应对 |
|------|------|------|
| 外部 LLM 服务不可用 | S2~S4 问答/解析功能降级 | Demo 模式兜底，开发和测试不依赖外部 API |
| 新浪财经接口变更/不可用 | S4 行情查询失效 | Demo 行情数据兜底 |
| JSON 文件并发写入冲突 | 数据损坏 | 单实例部署 + Storage 单例模式（教学版无并发风险） |
| 研报格式多样性 | 解析准确率不稳定 | 明确支持 3 种格式 + 异常兜底 |
