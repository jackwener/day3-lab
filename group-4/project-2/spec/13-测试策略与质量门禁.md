## 4. 质量门禁

### 4.1 发布门禁

| 门禁项 | 标准 | 阻断级别 |
|--------|------|----------|
| P0 测试用例 | 100% 通过 | 🔴 阻断发布 |
| P1 测试用例 | ≥80% 通过 | 🟡 需评审 |
| P2 测试用例 | ≥50% 通过 | 🟢 不阻断 |
| TypeScript 编译 | 零错误 | 🔴 阻断发布 |
| Lighthouse 性能 | ≥70 分 | 🟡 需评审 |
| 移动端布局 | 无布局破坏 | 🔴 阻断发布 |

### 4.2 缺陷分级

| 级别 | 定义 | 处理时限 | 示例 |
|------|------|----------|------|
| S1-致命 | 核心流程阻断 | 立即修复 | 无法抽卡、无法翻转、白屏 |
| S2-严重 | 功能异常但可绕过 | 当天修复 | 结局计算错误、状态条不显示 |
| S3-一般 | 非核心功能问题 | 下一迭代 | 图册排序不对、暖场标签缺失 |
| S4-建议 | 体验优化项 | 待排期 | 动画不够流畅、文案可改进 |
