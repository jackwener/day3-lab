## S-01 需求澄清会议 — 研报审核助手功能定义

| 项       | 内容                 |
| -------- | -------------------- |
| 时间     | 2026-04-15           |
| 地点     | 线下沟通             |
| 参会人员 | 产品经理、技术负责人 |

### 审核对象确认

| 项       | 结论                               |
| -------- | ---------------------------------- |
| 审核对象 | **内部研究员撰写的研报**           |
| 审核时机 | 研报发布前的质量把关环节           |
| 审核目的 | 确保研报符合合规要求，内容要素完整 |

### 审核模式定义

| 审核模式            | 说明                       | 适用场景                   |
| ------------------- | -------------------------- | -------------------------- |
| **规则审核**        | 基于预设规则的自动化检查   | 快速初筛，标准化检查       |
| **AI审核**          | 基于大模型的智能内容审核   | 语义理解，复杂场景判断     |
| **规则+AI联合审核** | 规则与AI双重校验，综合评分 | 重要研报终审，降低漏检风险 |

### 痛点记录

| 痛点                                 | 优先级 | 负责人   | 当前解决方式       |
| ------------------------------------ | ------ | -------- | ------------------ |
| 人工审核效率低，单份研报审核耗时长   | P0     | 质检员   | 人工逐字阅读检查   |
| 合规风险漏检，敏感信息识别依赖经验   | P0     | 合规专员 | 人工经验判断       |
| 审核标准不统一，不同审核员结果差异大 | P1     | 质检主管 | 依靠审核员个人经验 |
| 审核记录追溯困难，问题定位耗时       | P2     | IT部     | 纸质或零散电子记录 |

### 需求记录

1. **合规审核**：自动检测敏感信息泄露、政治敏感词等违规内容
2. **内容审核**：检查风险提示是否完整、数据来源是否标注
3. **多模式审核**：支持规则审核、AI审核、规则+AI联合审核三种模式
4. **审核报告**：生成结构化审核报告，标注问题位置及修改建议
5. **审核追溯**：保存审核历史，支持问题溯源与统计分析

| 项       | 内容                                |
| -------- | ----------------------------------- |
| 梳理人   | 合规专员、质检主管                  |
| 时间     | 2026-04-15                          |
| 审核模式 | 规则审核 / AI审核 / 规则+AI联合审核 |

### 合规审核规则

| 规则ID | 检查项           | 重要性 | 审核模式           | 示例违规内容                                     |
| ------ | ---------------- | ------ | ------------------ | ------------------------------------------------ |
| R-C-01 | 敏感信息泄露检测 | P0     | AI审核 / 规则+AI   | 未公开的内幕信息、客户持仓明细、未披露的重大事项 |
| R-C-02 | 政治敏感词检测   | P1     | 规则审核 / 规则+AI | 涉及政治人物的敏感表述、不当政治评论             |

### 内容审核规则

| 规则ID  | 检查项         | 重要性 | 审核模式           | 判定标准                                     |
| ------- | -------------- | ------ | ------------------ | -------------------------------------------- |
| R-CO-01 | 风险提示完整性 | P0     | AI审核 / 规则+AI   | 研报必须包含明确的风险提示段落               |
| R-CO-02 | 数据来源标注   | P0     | 规则审核 / 规则+AI | 引用的数据必须标注来源（如"数据来源：Wind"） |

### 审核模式选择建议

| 研报类型          | 推荐审核模式      | 理由                   |
| ----------------- | ----------------- | ---------------------- |
| 常规日报/周报     | 规则审核          | 格式固定，规则覆盖率高 |
| 深度研究报告      | AI审核 或 规则+AI | 内容复杂，需语义理解   |
| 涉及敏感行业/公司 | 规则+AI联合审核   | 双重校验，降低合规风险 |
| 首次覆盖报告      | 规则+AI联合审核   | 重要性强，需严格把关   |

## S-03 用户访谈 — 质检员工作调研

| 项       | 内容                          |
| -------- | ----------------------------- |
| 访谈对象 | 王质检（研报质检员，3年经验） |
| 访谈人   | 产品经理                      |
| 时间     | 2026-04-15                    |
| 方式     | 线下访谈                      |

| 问题                               | 回答要点                                                             |
| ---------------------------------- | -------------------------------------------------------------------- |
| Q1：当前审核一份研报平均耗时多久？ | 简单研报10-15分钟，深度报告30-45分钟。每天审核15-20份，工作强度大。  |
| Q2：最容易漏检的问题是什么？       | 敏感信息最难发现，特别是隐晦的表述。数据来源缺失也经常漏掉。         |
| Q3：对AI审核的期待？               | 希望能先自动筛一遍，标出可疑位置，我再重点看。能省一半时间就很好了。 |
| Q4：审核报告需要包含什么？         | 问题位置、严重程度、修改建议。最好能手改后重新提交审核。             |
| Q5：三种审核模式如何选择？         | 日常用规则审核快速过，重要报告用联合审核，AI审核适合语义类检查。     |

**总结：** ①AI预审+人工复核是核心诉求 ②问题定位准确比全面更重要 ③审核模式需灵活可选
