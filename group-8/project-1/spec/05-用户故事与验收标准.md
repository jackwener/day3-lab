## 字段说明 — 每条 UserStory 必须包含以下字段

| 字段         | 填写说明                                   | 数据来源 ←              | 流向下游 →                                     |
| ------------ | ------------------------------------------ | ----------------------- | ---------------------------------------------- |
| **需求编号** | 唯一编号，如 REQ-M2RV-001                  | ← `02` 采集编号         | → `14` 追踪矩阵首列                            |
| **故事**     | 作为【角色】，我希望【行为】，以便【价值】 | ← `04` PRD 场景拆解     | → `06` FSD 功能点                              |

| **来源**     | 对应 03/04 哪一条需求                      | ← `03` 范围 · `04` 场景 |                                                |
| **前置条件** | 触发该故事的前提状态                       | ← `04` 用户流程         | → `13` 测试前置                                |
| **功能对齐** | 对应功能规格 + 非功能约束                  |                         | → `06` FSD · `07` NFR                          |

| **验收标准** | AC，每条可独立验证                         | ← 故事 + `07` NFR       | → `13` 测试用例依据                            |

## US-001（P0）提交研报审核

| 字段         | 内容                                                                                     |
| ------------ | ---------------------------------------------------------------------------------------- |
| **需求编号** | REQ-M2RV-001                                                                             |
| **故事**     | 作为质检员，我希望上传研报文件并选择审核模式提交审核，以便快速启动自动化合规审核流程     |
| **优先级**   | P0                                                                                       |
| **来源**     | ← 03 §3 范围 / 04 §3 SC-01                                                               |
| **前置条件** | 用户已进入系统主界面，准备好待审核的研报文件（PDF/DOCX/DOC，≤50MB）                      |
| **功能对齐** | → 06 §F-01 文件上传 · 06 §F-02 规则引擎 · 06 §F-03 AI引擎 · 06 §F-04 联合审核 · 07 §性能 |
| **设计对齐** | → 08 §审核流程 · 09 POST /api/v1/reviews · 10 reviews表 · 11 §文件校验                   |
| **验证对齐** | → 13 TC-M2RV-001~003 · 14 第1行                                                          |

| 验收标准  | 描述（Given / When / Then）                                                                                                                                                                                                                                                                                            |
| --------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| AC-001-01 | **Given** 用户在审核提交页面且已选择一个合法文件（PDF/DOCX/DOC，≤50MB）；**When** 用户选择研报类型（日报/周报/深度研究/首次覆盖/行业报告）、审核模式（规则/AI/联合）并点击"提交审核"；**Then** 系统返回 HTTP 201，生成审核记录 ID（格式 `RV-{年份}-{4位序号}`），状态置为 `pending`，随即转为 `reviewing` 进入审核流程 |
| AC-001-02 | **Given** 用户上传了不支持的文件格式（如 .xlsx, .txt）；**When** 提交审核；**Then** 系统返回 `UNSUPPORTED_FILE_TYPE` 错误，前端显示"不支持的文件格式，仅支持 .pdf, .docx, .doc"，不创建审核记录                                                                                                                        |
| AC-001-03 | **Given** 用户上传文件大小超过 50MB；**When** 提交审核；**Then** 系统返回 `FILE_TOO_LARGE` 错误，前端显示"文件大小超过50MB限制"，不创建审核记录                                                                                                                                                                        |

| **故事**     | 作为质检员，我希望在提交审核后实时查看审核进度和当前步骤，以便了解审核执行状态    |
| **优先级**   | P0                                                                                |
| **来源**     | ← 04 §3 SC-01 / 04 §4 F-05                                                        |
| **前置条件** | 已提交一条审核记录，审核状态为 `reviewing`                                        |
| **功能对齐** | → 06 §F-05 · 07 §性能                                                             |
| **设计对齐** | → 08 §审核流程 · 09 GET /api/v1/reviews/{id}/status · 10 reviews表 · 11 §数据完整 |
| **验证对齐** | → 13 TC-M2RV-004~005 · 14 第2行                                                   |

| 验收标准  | 描述（Given / When / Then）                                                                                                                                                                                                                                             |
| --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| AC-002-01 | **Given** 审核记录处于 `reviewing` 状态；**When** 前端轮询 `GET /api/v1/reviews/{id}/status`；**Then** 返回当前进度百分比（0~100）、当前步骤名称（文件解析 → 合规规则匹配 → AI语义分析 → 数据来源交叉验证 → 生成审核报告）及各步骤状态（pending/in_progress/completed） |
| AC-002-02 | **Given** 审核记录已完成（状态为 passed/failed/warning）；**When** 查询状态；**Then** 返回最终评分 `score`、问题数统计（complianceIssues / contentIssues）及完成时间 `completedAt`                                                                                      |

| --------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

| **优先级**   | P1                                                                                   |
| **来源**     | ← 04 §3 SC-05 / 04 §4 F-08                                                           |

| 验收标准  | 描述（Given / When / Then）                                                                                                                                                                                                                       |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| AC-006-01 | **Given** 合规专员进入规则管理页面；**When** 页面加载完成（`GET /api/v1/rules`）；**Then** 展示全部规则列表，每条含 id / name / category / severity / mode（适用模式数组）/ description / enabled 状态，支持按 category（compliance/content）筛选 |

| AC-006-03 | **Given** 禁用了某条 P0 级规则；**When** 提交新的审核任务；**Then** 审核结果中不包含该规则的检测项，但其他已启用规则仍正常执行                                                                                                                    |

| AC-008-03 | **Given** 用户选择审核模式为 `combined`；**When** 提交审核；**Then** 系统同时执行规则引擎和 AI 引擎，合并两者问题列表后综合评分，覆盖所有检测维度                                                                         |
