## 1. 性能需求

### 1.1 延迟 SLO

| 指标                     | 目标值            | 度量方式               | 来源                                   |
| ------------------------ | ----------------- | ---------------------- | -------------------------------------- |
| **页面首屏加载**         | ≤ **3000ms**      | 浏览器 Performance API | 前端静态文件直接打开                   |
| **API P95 响应**         | ≤ **2000ms**      | Flask 服务端计时       | 除审核提交外的所有 GET 端点            |
| **文件上传处理**         | ≤ **60s**（50MB） | 服务端计时             | `POST /api/v1/reviews` 文件保存 + 校验 |
| **审核处理（规则模式）** | ≤ **30s** / 份    | 后台线程计时           | `04` §8 NFR                            |
| **审核处理（AI 模式）**  | ≤ **3min** / 份   | 后台线程计时           | `04` §8 NFR                            |
| **审核处理（联合模式）** | ≤ **3min** / 份   | 后台线程计时           | 规则 + AI 串行执行                     |
| **仪表盘统计查询**       | ≤ **1000ms**      | 服务端计时             | SQLite 聚合查询                        |

### 1.2 吞吐量

| 指标            | 目标值 | 说明                                           |
| --------------- | ------ | ---------------------------------------------- |
| 并发审核任务    | ≤ 5    | 单机 Flask + 后台线程，受 CPU/内存限制         |
| 单文件最大体积  | 50MB   | `Config.MAX_CONTENT_LENGTH = 50 * 1024 * 1024` |
| SQLite 写入并发 | 1      | SQLite WAL 模式下支持单写多读                  |

### 1.3 降级策略

**AI 审核降级**：

```
review_service.start_review(review_id)
  ├─[1] 规则引擎（rule_service.execute_rules）→ 始终执行
  ├─[2] AI 语义分析（ai_service.analyze）→ 仅 ai/combined 模式
  └─[3] 若 AI 不可用 → 返回 503 AI_SERVICE_UNAVAILABLE
```

| 约束                 | 说明                                                  |
| -------------------- | ----------------------------------------------------- |
| 规则审核**始终可用** | 不依赖外部服务，纯 Python 规则匹配                    |
| AI 审核降级          | AI 服务不可用时，combined 模式降级为纯规则审核        |
| 审核失败兜底         | 后台线程异常时，审核状态标记为 `failed`，记录错误信息 |

## 2. 可用性 / 可靠性需求

| 指标           | 目标值              | 说明                             |
| -------------- | ------------------- | -------------------------------- |
| 服务可用性     | **95%**（开发环境） | 单实例 Flask dev server，不设 HA |
| MTTR           | < 5 分钟            | 重启 Flask 进程即可恢复          |
| 数据持久性     | SQLite 文件级       | `instance/reviews.db` 单文件存储 |
| 上传文件持久性 | 本地磁盘            | `uploads/` 目录，无冗余备份      |

| 故障模式        | 影响                 | 恢复方式              |
| --------------- | -------------------- | --------------------- |
| Flask 进程崩溃  | 全部服务不可用       | 手动重启 `flask run`  |
| SQLite 文件损坏 | 数据丢失             | 从备份恢复 `.db` 文件 |
| 上传文件丢失    | 审核记录关联文件缺失 | 需重新上传            |
| AI 服务不可用   | AI/联合模式审核失败  | 切换为纯规则模式      |

## 3. 安全与合规需求

> 安全设计详见 `11` 安全设计规格。此处列出约束底线。

| 项       | 当前实现                 | 说明                               |
| -------- | ------------------------ | ---------------------------------- |
| API 认证 | 无（开放访问）           | MVP 阶段，`04` §5 明确暂不实现认证 |
| CORS     | 全开放（`origins: "*"`） | `__init__.py` 中配置，生产需白名单 |
| 速率限制 | 无                       | 开发环境不限速                     |

### 3.1 文件安全

| 约束           | 规格                             | 来源                                      |
| -------------- | -------------------------------- | ----------------------------------------- |
| 文件类型白名单 | 仅允许 `.pdf` / `.docx` / `.doc` | `validators.py` `ALLOWED_EXTENSIONS`      |
| 文件大小限制   | ≤ 50MB                           | `config.py` `MAX_CONTENT_LENGTH`          |
| 文件名安全     | UUID 重命名，防路径遍历          | `file_service.py` 使用 `uuid.uuid4().hex` |

### 3.2 敏感数据保护

| 数据类型                | 保护方式                                 |
| ----------------------- | ---------------------------------------- |
| AI API Key（DashScope） | 环境变量存储（`.env`），禁止硬编码       |
| SECRET_KEY              | 环境变量存储，默认值仅用于开发           |
| 上传研报文件            | 本地 `uploads/` 目录存储，不对外暴露路径 |

## 5. 可维护性 / 可观测性需求

### 5.1 日志

| 项       | 规格                                             |
| -------- | ------------------------------------------------ |
| 日志框架 | Flask 内置 `app.logger`（基于 Python `logging`） |
| 日志级别 | 开发环境 `DEBUG`，生产环境 `INFO`                |
| 请求日志 | Flask 自动记录每个 HTTP 请求                     |
| 错误日志 | 全局错误处理器（`errors.py`）捕获并记录异常      |

### 5.2 链路追踪

| 项           | 规格                                                            |
| ------------ | --------------------------------------------------------------- |
| traceId 格式 | `tr_{uuid.hex}`（32 位十六进制）                                |
| 注入位置     | 所有成功响应顶层 `traceId` + 错误响应 `error.traceId`           |
| 实现方式     | `response.py` 中 `success_response` / `error_response` 自动注入 |

### 5.3 数据库可观测性

| 项           | 规格                                                     |
| ------------ | -------------------------------------------------------- |
| 数据库文件   | `instance/report_audit.db`，可直接使用 SQLite 客户端查看 |
| ORM 查询日志 | `SQLALCHEMY_ECHO = True`（开发环境可选开启）             |

### 5.4 API 文档

| 项       | 规格                              |
| -------- | --------------------------------- |

## 6. 约束

### 6.1 技术约束

| 约束     | 说明                                                                  |
| -------- | --------------------------------------------------------------------- |
| 后端语言 | Python 3.11+，不得引入其他语言运行时                                  |
| Web 框架 | Flask 3.x，不切换为 FastAPI/Django                                    |
| 数据库   | SQLite，不引入 PostgreSQL/MySQL 等外部数据库服务                      |
| ORM      | SQLAlchemy，不直接拼接 SQL                                            |
| 前端     | 原生 HTML5 + JavaScript + Tailwind CSS (CDN)，不引入 React/Vue 等框架 |
| 部署     | Flask dev server（port 5000），前端静态文件浏览器直接打开             |

### 6.2 业务约束

| 约束     | 说明                                                                         |
| -------- | ---------------------------------------------------------------------------- |
| AI 审核  | 当前为模拟实现（`ai_service.py`），依赖 DashScope API Key                    |
| 认证权限 | MVP 阶段不实现，所有端点开放访问                                             |
| 文件格式 | 仅支持 PDF / DOCX / DOC，不支持 HTML / PPT / URL                             |
| 审核规则 | 内置 8 条预置规则（`rule_service.py` `BUILTIN_RULES`），不支持用户自定义规则 |

### 6.3 资源约束

| 约束     | 说明                                  |
| -------- | ------------------------------------- |
| 部署环境 | 单机开发环境，不部署到云服务器        |
| 并发能力 | Flask 单进程 + 后台线程，不支持高并发 |
| 存储容量 | 受本地磁盘限制，无分布式存储          |
| 无 CI/CD | 手动部署，无自动化流水线              |
