## 1. 安全目标与合规要求

> 明确本模块需遵循的安全目标和外部合规标准。研报审核场景关注文件安全与数据完整性。

| 安全目标     | 说明                                           | 对应合规         |
| ------------ | ---------------------------------------------- | ---------------- |
| 文件上传安全 | 仅允许白名单格式文件，防止恶意文件上传         | 安全开发规范     |

## 3. 数据安全

### 3.1 数据分类与分级

| 数据类型 | 安全等级 | 示例                        | 保护措施                          |
| -------- | -------- | --------------------------- | --------------------------------- |
| 研报文件 | **内部** | PDF/DOCX 研报文件           | 本地 `uploads/` 存储，UUID 重命名 |
| 审核记录 | **内部** | Review 评分、状态、问题列表 | SQLite 存储，ORM 访问             |
| 审核规则 | 一般     | 内置规则定义                | 数据库存储，可启用/禁用           |
| 系统配置 | **敏感** | API Key、SECRET_KEY         | 环境变量存储，不入代码仓库        |

### 3.2 文件安全

> 对齐 `07` §3.1 文件安全。

| 安全措施           | 实现方式                         | 代码位置                                                           |
| ------------------ | -------------------------------- | ------------------------------------------------------------------ |
| **文件类型白名单** | 仅允许 `.pdf` / `.docx` / `.doc` | `validators.py` `ALLOWED_EXTENSIONS = {'.pdf', '.docx', '.doc'}`   |
| **文件大小限制**   | ≤ 50MB                           | `config.py` `MAX_CONTENT_LENGTH = 50 * 1024 * 1024`                |
| **文件名安全**     | UUID 重命名，防路径遍历          | `file_service.py` `uuid.uuid4().hex + ext`                         |
| **文件大小校验**   | 服务端二次校验                   | `validators.py` `validate_file_size()` seek 到文件末尾获取真实大小 |

**文件类型校验流程**：

```
file_service.save_file(file_storage)
  ├─ validators.allowed_file(filename) → 检查扩展名白名单
  ├─ validators.validate_file_size(file_storage) → 检查文件大小 ≤ 50MB
  ├─ uuid.uuid4().hex + ext → 生成安全文件名
  └─ file_storage.save(file_path) → 保存到 uploads/ 目录
```

### 3.3 加密策略

| 场景     | 加密方式            | 说明                                   |
| -------- | ------------------- | -------------------------------------- |
| 传输加密 | 无（开发环境 HTTP） | 生产环境需 TLS 1.2+                    |
| 存储加密 | 无（开发环境）      | SQLite 文件未加密，生产需 SQLCipher    |
| 密钥管理 | 环境变量 `.env`     | `python-dotenv` 加载，密钥不入代码仓库 |

| 项       | 当前配置        | 代码位置                                                           |
| -------- | --------------- | ------------------------------------------------------------------ |

| 允许方法 | 全部            | Flask-CORS 默认                                                    |
| 允许头部 | 全部            | Flask-CORS 默认                                                    |

> **生产改进**：将 `origins: "*"` 替换为前端域名白名单。

## 4. 接口安全

> 与 `09` API 规格配合，定义 API 层面的安全防护措施。

| 防护措施     | 实现方式                               | 说明                                                         |
| ------------ | -------------------------------------- | ------------------------------------------------------------ |
| 输入校验     | 服务端白名单校验                       | `validators.py` 对 mode/reportType/page/pageSize/date 做校验 |
| SQL 注入防护 | SQLAlchemy ORM 参数化查询              | 禁止字符串拼接 SQL，所有查询通过 ORM                         |
| XSS 防护     | Flask Jinja2 自动转义 + 前端渲染时注意 | API 返回 JSON，前端需注意 DOM 插入                           |
| CSRF 防护    | 无                                     | REST API 无 session cookie，暂不启用                         |
| 速率限制     | 无                                     | 开发环境不限速                                               |
| 文件上传校验 | 类型白名单 + 大小限制                  | 仅允许 PDF/DOCX/DOC，≤ 50MB                                  |

### 4.1 错误码与安全信息暴露

| 错误码                  | 是否安全 | 说明                                    |
| ----------------------- | -------- | --------------------------------------- |
| `INVALID_REQUEST`       | ✓        | 通用参数错误，不暴露内部细节            |
| `FILE_TOO_LARGE`        | ✓        | 仅提示大小超限                          |
| `UNSUPPORTED_FILE_TYPE` | ✓        | 仅提示格式不支持                        |
| `REVIEW_NOT_FOUND`      | ✓        | 仅返回 `{"id": "<id>"}`，不暴露是否存在 |
| `INTERNAL_ERROR`        | ✓        | 通用内部错误，不暴露堆栈信息            |

## 5. AI 服务安全

> 针对 DashScope AI 审核服务的安全措施。

| 风险点             | 防护措施                                    | 验收标准                |
| ------------------ | ------------------------------------------- | ----------------------- |
| API Key 泄露       | 环境变量存储（`.env`），禁止硬编码          | 代码审计无硬编码 Key    |
| AI 服务不可用      | 返回 `503 AI_SERVICE_UNAVAILABLE`           | API 响应正确错误码      |
| AI 审核为模拟实现  | 当前 `ai_service.py` 为模拟，不发送真实数据 | MVP 阶段明确标识        |
| 研报内容发送至外部 | 仅在配置 API Key 后发送至 DashScope         | 无 Key 时 AI 功能不可用 |

## 6. 审计与日志

> 当前版本无独立审计日志系统，依赖 Flask 内置日志。

| 事件类型  | 记录方式                 | 保留期限     | 说明                    |
| --------- | ------------------------ | ------------ | ----------------------- |
| HTTP 请求 | Flask 内置请求日志       | 进程生命周期 | 每次请求自动记录        |
| 文件上传  | `file_service.py` 日志   | 进程生命周期 | 记录文件名、大小        |
| 审核执行  | `review_service.py` 日志 | 进程生命周期 | 记录审核 ID、步骤、结果 |
| 错误异常  | `errors.py` 全局错误处理 | 进程生命周期 | 记录错误码、消息        |

> **生产改进**：引入结构化日志（如 `structlog`），持久化到文件或日志服务，保留 ≥ 90 天。

## 7. 安全威胁清单（STRIDE 简表）

| 类型              | 威胁                         | 风险等级 | 应对措施                               |
| ----------------- | ---------------------------- | -------- | -------------------------------------- |
| **S**（伪装）     | 无认证，任何人可访问所有端点 | **高**   | MVP 接受，生产引入 JWT                 |
| **T**（篡改）     | HTTP 明文传输，数据可被篡改  | 中       | 生产环境强制 HTTPS                     |
| **R**（否认）     | 无审计日志，操作不可追溯     | 中       | 生产引入审计日志                       |
| **I**（信息泄露） | API Key 可能泄露             | **高**   | 环境变量存储，`.env` 加入 `.gitignore` |
| **D**（拒绝服务） | 无速率限制，可被大量请求攻击 | 低       | 开发环境资源充足，生产引入限速         |
| **E**（权限提升） | 无角色权限，所有操作均可执行 | 中       | 生产引入 RBAC 权限模型                 |
