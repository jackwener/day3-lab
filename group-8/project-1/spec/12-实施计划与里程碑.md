## 7. 依赖与风险

**依赖链**：

**Sprint 1 需求+设计** → **Sprint 2 核心开发**（先定契约再写代码）→ **Sprint 3 测试+部署**（先写完再测）

| 风险                     | 影响                                | 应对                                             |
| ------------------------ | ----------------------------------- | ------------------------------------------------ |
| AI 审核外部 LLM 不可用   | AI/联合模式审核无法执行真实语义分析 | Mock AI 服务兜底（关键词匹配），降级为规则审核   |
| PDF 解析库兼容性问题     | 部分 PDF 文件无法正确解析文本       | pdfplumber 优先，PyPDF2 回退，解析失败返回默认值 |
| 前端 CDN 依赖不可用      | Tailwind CSS / Chart.js 加载失败    | 备选方案：本地引入静态资源                       |
| 单机 SQLite 并发写入冲突 | 多个审核任务同时写入数据库锁等待    | WAL 模式 + 后台线程串行化审核写入                |
| 开发周期紧张（10 天）    | 功能不完整或质量不达标              | P0 功能优先保证，P2 功能（导出）可延后           |
