## 一、升级概述

本轮功能升级聚焦**研报分析模块增强**，在 M1-QA 基线版本之上新增 6 项功能：

| 编号 | 功能点 | 优先级 |
|------|--------|--------|
| F-01 | 研报对比增加股票代码提取 + 股票详情弹窗（Mock 数据） | P0 |
| F-02 | 研报观点支持定位到原文引用 | P0 |
| F-03 | 研报对比调整为列表勾选交互 | P0 |
| F-04 | 研报对比支持删除功能 | P0 |
| F-05 | 研报对比增加共同观点与差异观点分析（预计算存储） | P1 |
| F-06 | 增加研报知识库，支持全局研报管理与跨会话勾选对比 | P1 |
