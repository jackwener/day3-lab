### 痛点记录

| 痛点 | 优先级 | 负责人 |
|------|--------|--------|
| 研报对比缺少股票代码关联，无法快速查看标的公司基本面数据 | P0 | 李总监 |
| 研报核心观点无法定位到原文，复核时需手动翻找 PDF 原文 | P0 | 李总监 |
| 研报对比交互不直观，当前卡片式选择不适合大量研报场景 | P0 | 王经理 |
| 对比结果无法删除清理，历史对比数据越积越多 | P0 | 张产品 |
| 多份研报间共同观点和差异点需人工归纳，耗时且易遗漏 | P1 | 李总监 |
| 研报按会话管理，跨会话无法统一查看已上传研报 | P1 | 王经理 |

### 需求记录

1. **股票代码提取与详情**：从研报文本中自动提取股票代码（如 SH600519、000858.SZ），点击后弹出详情页展示股价走势、财报、时点数据（MVP 阶段采用 Mock 数据）
2. **观点原文定位**：研报核心观点支持点击跳转到原文引用位置，高亮展示原文上下文
3. **对比交互优化**：研报对比从卡片式改为列表勾选形式，更直观地管理待对比研报
4. **对比删除功能**：支持删除已完成的对比结果和移除对比列表中的研报
5. **智能观点对比**：解析阶段预计算各研报观点的语义相似度，对比时自动展示共同观点与差异观点
6. **研报知识库**：新增全局研报管理视图，支持跨会话管理已上传研报，支持在知识库中勾选进行对比
