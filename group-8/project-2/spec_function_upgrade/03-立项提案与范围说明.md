## 1. 背景与问题

> V1 版本已交付研报上传解析和基础对比功能。本轮升级基于用户反馈和产品规划，解决以下痛点：

| 痛点 | 来源 |
|------|------|
| 研报缺少股票代码关联，无法从研报直达标的公司基本面数据 | S-01 产品评审 · FB-05 |
| 核心观点无法溯源到原文，分析师不敢直接引用 AI 提取结果 | S-01 · FB-02 |
| 研报对比交互不友好，卡片式选择在大量研报时效率低 | S-01 · FB-06 |
| 对比结果无法删除，历史数据越积越多 | S-01 · FB-04 |
| 多份研报间缺乏共同观点和差异观点的智能归纳 | S-01 · FB-01 |
| 研报绑定会话，无法跨会话统一管理和对比 | S-01 · FB-03 |

## 2. 提案概要

在现有投研问答助手应用内交付**研报分析增强**能力：① 研报解析时自动提取股票代码，支持点击查看 Mock 股票详情；② 核心观点关联原文位置，支持一键定位引用；③ 研报对比改为列表勾选交互并支持删除操作；④ 解析阶段预计算观点相似度，对比时自动展示共同/差异观点；⑤ 新增研报知识库，支持全局研报管理与跨会话对比。

## 3. 范围边界

| 做（范围内） | 不做（范围外） |
|-------------|---------------|
| 从研报文本中提取股票代码（正则匹配） | 实时接入真实股票行情 API |
| 股票详情弹窗展示 Mock 数据（股价走势、财报、时点数据） | 股票交易功能 |
| 核心观点记录原文偏移位置，前端高亮展示 | PDF 原文在线预览/翻页 |
| 研报对比调整为列表勾选交互 | 自定义对比维度配置 |
| 研报/对比结果删除功能 | 对比结果导出为 Excel/PDF |
| 解析阶段预计算共同/差异观点（文本相似度） | 实时 LLM 语义分析 |
| 全局研报知识库（跨会话列表 + 搜索 + 勾选对比） | 研报内容全文检索 |

## 4. 成功标准（可度量）

| 标准 | 度量方式 |
|------|----------|
| 股票代码提取准确率 | 含股票代码的研报中，≥80% 能正确提取至少一个股票代码 |
| 观点原文定位可用 | 提取的核心观点 100% 可点击定位到原文段落 |
| 对比交互升级 | 列表勾选 + 删除全流程在 30 秒内可演示完毕 |
| 共同/差异观点展示 | 2 份及以上研报对比时自动展示共同观点和差异观点分组 |
| 知识库可用 | 跨会话研报列表 + 勾选对比全流程在 1 分钟内可演示完毕 |

## 5. 风险（简表）

| 风险 | 影响 | 应对 |
|------|------|------|
| 股票代码格式多样（SH600519 / 000858.SZ / 代码: 600519 等） | 提取遗漏 | 多模式正则 + 持续补充 |
| 研报观点定位精度不够（原文变动/截断） | 用户体验差 | 模糊匹配 + 上下文扩展 |
| 观点相似度预计算耗时较长 | 上传延迟 | 异步计算，不阻塞上传响应 |
| 研报从会话级改为全局级，数据模型变更大 | 兼容性风险 | 保留 session_id 字段兼容旧数据 |
