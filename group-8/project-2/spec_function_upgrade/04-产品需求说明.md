> **04 的定位**：`03` 说了"为什么做"，04 翻译成"做什么、不做什么、多重要"。`05` 再拆成用户故事和验收标准。

## 1. 愿景与目标

| 03 痛点 | 04 目标 |
|---------|---------|
| 研报缺少股票代码关联 | 解析时自动提取股票代码，支持一键查看标的公司 Mock 基本面数据 |
| 核心观点无法溯源到原文 | 每条观点关联原文位置，支持点击定位高亮展示 |
| 对比交互不友好 | 列表勾选式对比交互，高效管理待对比研报 |
| 对比结果无法删除 | 支持删除研报和对比结果 |
| 缺乏智能观点归纳 | 预计算观点相似度，自动展示共同观点与差异观点 |
| 研报绑定会话无法全局管理 | 全局研报知识库，跨会话管理与对比 |

## 2. 目标用户

| 角色 | 使用目标 | 频率 |
|------|----------|------|
| 投研分析师 | 查看研报关联股票基本面，快速验证观点并溯源原文 | 每天多次 |
| 研究部经理 | 跨研报对比共同/差异观点，审阅多机构对标的的看法 | 每周多次 |
| IT 运维人员 | 管理研报知识库存储空间，清理过期数据 | 按需 |

## 3. 核心业务场景

| 编号 | 场景名 | 用户路径 |
|------|--------|----------|
| SC-05 | 股票代码查看详情 | 用户查看研报详情 → 看到提取的股票代码（可点击）→ 点击代码弹出详情页 → 查看股价走势/财报/时点数据（Mock） |
| SC-06 | 观点原文定位 | 用户查看研报核心观点 → 点击某条观点旁的"定位原文"按钮 → 弹窗展示原文内容并高亮对应段落 |
| SC-07 | 列表勾选对比 | 用户进入研报分析/知识库 → 在列表中勾选 2~5 份研报 → 点击"对比"按钮 → 查看对比表 |
| SC-08 | 删除研报/对比 | 用户在研报列表中点击删除按钮 → 确认弹窗 → 研报被删除 |
| SC-09 | 共同/差异观点对比 | 用户勾选研报触发对比 → 对比结果展示共同观点区域 + 差异观点区域 |
| SC-10 | 研报知识库管理 | 用户点击"知识库"Tab → 查看全部已上传研报 → 支持搜索/筛选/勾选对比 |

## 4. 产品规则

| 编号 | 规则 | 来源 |
|------|------|------|
| R-06 | 股票代码提取格式支持：SH/SZ+6位数字、6位数字+.SH/.SZ、"股票代码"/"证券代码"+冒号+数字 | 03 §3 |
| R-07 | 每条核心观点 MUST 携带 `source_text`（原文片段）和 `position`（字符偏移） | 03 §3 |
| R-08 | 研报对比列表勾选模式：最少 2 份、最多 5 份，勾选时实时显示已选计数 | 03 §3 |
| R-09 | 删除研报时 MUST 确认弹窗，删除后级联清理关联的文件和对比数据 | 03 §3 |
| R-10 | 共同观点判定规则：两条观点文本相似度 ≥0.7 判定为共同观点 | 03 §3 |
| R-11 | 知识库研报列表支持按文件名/机构/股票代码筛选 | 03 §3 |

## 5. 能力与优先级

| 子能力 | 优先级 | 对应场景 |
|--------|--------|----------|
| 股票代码提取 + Mock 详情弹窗 | **P0** | SC-05 |
| 核心观点原文定位与高亮 | **P0** | SC-06 |
| 研报对比列表勾选交互 | **P0** | SC-07 |
| 研报删除功能 | **P0** | SC-08 |
| 共同/差异观点预计算与展示 | **P1** | SC-09 |
| 研报知识库（全局管理 + 跨会话对比） | **P1** | SC-10 |

## 6. 验收与成功标准（PRD 层）

| 标准 | 度量 |
|------|------|
| 股票代码可识别 | 上传含股票代码的研报后，详情页展示可点击的股票代码标签 |
| 观点可溯源 | 每条核心观点旁有"查看原文"按钮，点击弹窗显示高亮原文 |
| 对比交互流畅 | 从研报列表勾选到生成对比表，全流程 30 秒内可演示 |
| 共同/差异观点可见 | 对比结果清晰分组展示共同观点和差异观点 |
| 知识库全流程 | 跨会话研报列表 + 搜索 + 勾选对比，1 分钟内可演示 |
