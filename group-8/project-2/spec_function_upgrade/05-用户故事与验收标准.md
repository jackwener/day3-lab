## US-006（P0）股票代码提取与详情查看

| 字段 | 内容 |
|------|------|
| **需求编号** | REQ-M2RPT-001 |
| **故事** | 作为投研分析师，我希望研报解析时自动提取股票代码，并能点击代码查看股价走势、财报、时点数据，以便快速了解标的公司基本面 |
| **优先级** | P0 |
| **来源** | ← 03 §1 / 04 SC-05 |
| **前置条件** | 已上传并解析成功至少一份含股票代码的研报 |
| **功能对齐** | → 06 §13 股票详情弹窗 · 07 §1 |
| **设计对齐** | → 08 §9 · 09 GET /stock/{code}/detail · 10 §14 StockMock · 11 §4 |
| **验证对齐** | → 13 TC-M02-001~005 · 14 第 1 行 |

| 验收标准 | 描述（每条可独立测试） |
|----------|----------------------|
| AC-006-01 | 研报解析后，提取的股票代码以可点击标签形式展示在研报详情中 |
| AC-006-02 | 点击股票代码标签，弹出详情页展示股价走势折线图（Mock 数据） |
| AC-006-03 | 股票详情页包含：公司名称、当前价格、涨跌幅、近 30 日走势图、最近一期财报摘要、关键时点数据 |
| AC-006-04 | 股票代码支持格式：SH600519、000858.SZ、6位纯数字 |
| AC-006-05 | 研报中未识别到股票代码时，不展示股票代码区域 |

## US-007（P0）研报观点原文定位

| 字段 | 内容 |
|------|------|
| **需求编号** | REQ-M2RPT-002 |
| **故事** | 作为投研分析师，我希望点击研报核心观点后能定位到原文引用，以便验证 AI 提取结果的准确性 |
| **优先级** | P0 |
| **来源** | ← 03 §1 / 04 SC-06 |
| **前置条件** | 研报已解析成功，存在核心观点 |
| **功能对齐** | → 06 §14 原文定位弹窗 |
| **设计对齐** | → 09 GET /reports/{id} 含 source_text · 10 §9 extracted_data 扩展 |
| **验证对齐** | → 13 TC-M02-010~013 · 14 第 2 行 |

| 验收标准 | 描述（每条可独立测试） |
|----------|----------------------|

## US-008（P0）研报对比交互优化与删除

| 字段 | 内容 |
|------|------|
| **需求编号** | REQ-M2RPT-003 |
| **故事** | 作为投研分析师，我希望以列表勾选方式选择研报进行对比，并能删除不需要的研报，以便高效管理对比工作 |
| **优先级** | P0 |
| **来源** | ← 03 §1 / 04 SC-07, SC-08 |
| **前置条件** | 系统中已有 ≥2 份研报 |
| **功能对齐** | → 06 §15 研报列表勾选 · 06 §16 删除功能 |
| **设计对齐** | → 09 DELETE /reports/{id} · 09 POST /reports/compare |
| **验证对齐** | → 13 TC-M02-020~026 · 14 第 3 行 |

| 验收标准 | 描述（每条可独立测试） |
|----------|----------------------|
| AC-008-01 | 研报以表格列表形式展示，每行包含：勾选框、文件名、评级、目标价、股票代码、上传时间、操作按钮 |
| AC-008-02 | 勾选 2~5 份研报后，顶部出现"对比已选 (N)" 按钮 |
| AC-008-03 | 勾选不足 2 份时对比按钮禁用，超过 5 份时无法继续勾选 |
| AC-008-04 | 每行研报有"删除"按钮，点击弹出确认弹窗 |
| AC-008-05 | 确认删除后，研报从列表移除，关联的原始文件被清理 |
| AC-008-06 | 对比结果区域有"关闭"按钮，可关闭/清除对比结果 |

## US-009（P1）共同观点与差异观点对比

| 字段 | 内容 |
|------|------|
| **需求编号** | REQ-M2RPT-004 |
| **故事** | 作为研究部经理，我希望对比多份研报时能自动看到共同观点和差异观点分组，以便快速把握市场共识与分歧 |
| **优先级** | P1 |
| **来源** | ← 04 SC-09 |
| **前置条件** | 已选择 ≥2 份研报并触发对比 |
| **功能对齐** | → 06 §17 共同/差异观点展示 |
| **设计对齐** | → 09 POST /reports/compare 响应扩展 · 10 §15 观点相似度 |
| **验证对齐** | → 13 TC-M02-030~033 · 14 第 4 行 |

| 验收标准 | 描述（每条可独立测试） |
|----------|----------------------|
| AC-009-01 | 对比结果除原有维度对比表外，新增"共同观点"和"差异观点"两个区域 |
| AC-009-02 | 共同观点区域展示 ≥2 份研报中相似的观点，标注涉及的研报 |
| AC-009-03 | 差异观点区域展示各研报独有的观点，按研报分组 |
| AC-009-04 | 共同/差异观点在解析阶段预计算，对比时直接展示，无需等待 |

## US-010（P1）研报知识库

| 字段 | 内容 |
|------|------|
| **需求编号** | REQ-M2RPT-005 |
| **故事** | 作为投研分析师，我希望有一个统一的研报知识库，能跨会话查看和管理所有已上传研报，并在此勾选对比，以便高效复用历史研报 |
| **优先级** | P1 |
| **来源** | ← 04 SC-10 |
| **前置条件** | 系统中已有已上传研报 |
| **功能对齐** | → 06 §18 知识库页面 |
| **设计对齐** | → 09 GET /reports（无 session_id 过滤）· 10 Report 实体 |
| **验证对齐** | → 13 TC-M02-040~044 · 14 第 5 行 |

| 验收标准 | 描述（每条可独立测试） |
|----------|----------------------|
| AC-010-01 | 新增"知识库"Tab 入口，展示所有已上传研报（不限会话） |
| AC-010-02 | 知识库列表支持按文件名搜索 |
| AC-010-03 | 知识库列表支持按机构、股票代码筛选 |
| AC-010-04 | 知识库中支持勾选 2~5 份研报进行对比，交互同 US-008 |
| AC-010-05 | 知识库中支持删除研报，交互同 US-008 |
