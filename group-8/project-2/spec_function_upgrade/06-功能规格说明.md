## 13. 股票代码展示与详情弹窗

> 对齐 `05` US-006。描述股票代码的展示与交互规格。

### 13.1 股票代码标签

研报详情（信息卡片/列表行）中新增股票代码展示区域：

| 元素 | 规格 |
|------|------|
| **位置** | 研报详情卡片中，评级芯片右侧 |
| **样式** | 可点击标签，蓝色文字 + 下划线，hover 变色 |
| **内容** | 展示标准化后的股票代码（如 `SH600519`、`SZ000858`） |
| **多个代码** | 如提取到多个，横向排列，最多显示 3 个，超出显示 "+N" |

### 13.2 股票详情弹窗

点击股票代码标签后弹出模态框：

## 15. 研报列表勾选交互（对比优化）

> 对齐 `05` US-008。描述研报列表形式的勾选对比交互。

### 15.1 列表布局

替换原有卡片式研报展示，改为**表格列表**形式：

```
┌──┬────────────────────┬──────┬────────┬──────────┬────────────┬──────┐
│☐ │ 文件名              │ 评级  │ 目标价  │ 股票代码   │ 上传时间    │ 操作  │
├──┼────────────────────┼──────┼────────┼──────────┼────────────┼──────┤
│☑ │ 贵州茅台-中信.pdf    │ 买入  │ ¥2100  │ SH600519  │ 04-14 10:30│ 🗑️   │
│☐ │ 寒武纪-招商.pdf      │ 增持  │ ¥85    │ SH688256  │ 04-14 11:00│ 🗑️   │
│☑ │ 茅台-国泰.pdf       │ 增持  │ ¥1950  │ SH600519  │ 04-15 09:00│ 🗑️   │
└──┴────────────────────┴──────┴────────┴──────────┴────────────┴──────┘
                                              已选 2/5  [对比已选(2)]
```

### 15.2 勾选规则

| 规则 | 说明 |
|------|------|
| 最少勾选 | 2 份，不足时"对比已选"按钮禁用 |
| 最多勾选 | 5 份，达上限后未选行复选框置灰 |
| 计数显示 | 底部实时显示"已选 N/5" |
| 全选/取消 | 表头提供全选复选框（最多选前 5 个） |

### 15.3 列表排序

| 默认排序 | 按上传时间倒序 |
|----------|--------------|
| 可排序列 | 文件名、评级、上传时间 |

## 16. 研报删除功能

> 对齐 `05` US-008 AC-008-04/05。

| 交互 | 说明 |
|------|------|
| 触发 | 点击列表行中的 🗑️ 删除按钮 |
| 确认弹窗 | "确认删除研报「{file_name}」？此操作不可恢复。" |
| 确认后 | 调用 `DELETE /reports/{id}`，从列表移除，Toast 提示"删除成功" |
| 取消 | 关闭弹窗，不做操作 |
| 副作用 | 如该研报正在对比结果中，对比结果自动关闭 |

## 18. 研报知识库页面

> 对齐 `05` US-010。描述全局研报知识库的页面规格。

### 18.1 入口

| 元素 | 规格 |
|------|------|
| **位置** | 主 Tab 栏，新增"知识库"Tab（位于"问答"和"研报分析"之后） |
| **图标** | 📚 书本图标 |

### 18.2 页面布局

```
┌─────────────────────────────────────────────┐
│  搜索: [________________] 筛选: [机构▼] [代码▼] │
├─────────────────────────────────────────────┤
│  ☐ 文件名    │ 评级 │ 目标价 │ 代码  │ 机构 │ 时间  │ 操作 │
│  ☑ 茅台-中信  │ 买入 │ ¥2100 │ 600519│ 中信 │ 04-14 │ 🗑️  │
│  ☐ 寒武纪-招商│ 增持 │ ¥85   │ 688256│ 招商 │ 04-15 │ 🗑️  │
│  ☑ 茅台-高盛  │ 买入 │ ¥2200 │ 600519│ 高盛 │ 04-15 │ 🗑️  │
├─────────────────────────────────────────────┤
│                     已选 2/5  [对比已选(2)]    │
└─────────────────────────────────────────────┘
```

### 18.3 搜索与筛选

| 功能 | 规格 |
|------|------|
| 搜索 | 按文件名模糊匹配，实时过滤（debounce 300ms） |
| 机构筛选 | 下拉单选，选项从已有研报的 institution 字段聚合 |
| 股票代码筛选 | 下拉单选，选项从已有研报的 stock_codes 字段聚合 |
| 重置 | 点击"重置"清空所有筛选条件 |

### 18.4 与会话级研报的关系

| 场景 | 行为 |
|------|------|
| 知识库展示 | 显示所有研报，不区分会话 |
| 知识库对比 | 可跨不同会话的研报进行对比 |
| 知识库删除 | 删除研报同时从关联会话中移除 |
