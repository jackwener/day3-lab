## 1. 性能需求

### 1.1 延迟 SLO（新增/变更）

| 指标 | 目标值 | 度量方式 | 来源 |
|------|--------|----------|------|
| 股票详情接口 P95 延迟 | < **200ms** | Mock 数据直接返回 | 04 SC-05 |
| 研报解析（含股票代码+观点位置提取） | < **90s** | 与 V1 一致，新增提取项不应显著增加耗时 | 04 SC-05/06 |
| 对比接口（含共同/差异观点） | < **3000ms** | 预计算结果直接查询，不含实时计算 | 04 SC-09 |
| 知识库列表查询 | < **500ms** | JSON 文件全量读取 + 内存过滤 | 04 SC-10 |
| 研报删除 | < **500ms** | 元数据 + 文件清理 | 04 SC-08 |

### 1.2 观点相似度预计算

| 约束 | 说明 |
|------|------|
| 计算时机 | 研报上传解析完成后，异步触发 |
| 算法 | 基于文本 Jaccard 相似度或余弦相似度（TF-IDF） |
| 阈值 | 相似度 ≥ 0.7 判定为共同观点 |
| 存储 | 预计算结果存入 `opinion_similarity.json` |

## 2. 可用性需求（沿用基线）

沿用 M1-QA `07` §2 规格，无新增变更。

## 3. 可观测性需求

### 3.1 新增错误码

| HTTP | `error.code` | 触发条件 |
|------|--------------|----------|
| 404 | `STOCK_NOT_FOUND` | 股票代码在 Mock 数据中不存在 |
| 400 | `INVALID_STOCK_CODE` | 股票代码格式非法 |
| 404 | `REPORT_NOT_FOUND` | 删除/查询的研报不存在 |

## 4. 安全需求（新增）

| 项 | 当前实现 | 说明 |
|----|----------|------|
| 文件删除确认 | 前端二次确认弹窗 | 防止误删 |
| Mock 数据隔离 | Mock 数据只读，不接受外部写入 | 防止 Mock 数据被篡改 |

## 5. 数据约束（新增）

### 5.1 输入约束

| 约束 | 规格 | 来源 |
|------|------|------|
| `stock_code` 格式 | 匹配正则 `^(SH\|SZ)\d{6}$` 或 `^\d{6}\.(SH\|SZ)$` | 04 R-06 |
| 知识库搜索关键词 | ≤50 字符 | 06 §18 |
| 筛选字段 | institution / stock_code 为枚举值 | 06 §18 |

### 5.2 类型约束

| 字段 | 类型 | 约束 |
|------|------|------|
| `stock_codes` | `string[]` | 研报提取的股票代码数组 |
| `core_opinions[].source_text` | `string` | 原文片段，≤500 字符 |
| `core_opinions[].position` | `integer\|null` | 字符偏移位置，≥0 或 null |
| `common_opinions` | `object[]` | 共同观点列表 |
| `diff_opinions` | `object[]` | 差异观点列表 |

## 6. 兼容性需求

沿用 M1-QA `07` §6 规格，无新增变更。新增依赖：无（Mock 数据不依赖外部库）。
