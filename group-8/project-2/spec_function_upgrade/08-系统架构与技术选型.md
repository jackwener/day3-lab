## 2. 新增模块

### 2.1 Mock 股票数据模块

| 模块 | 文件 | 职责 |
|------|------|------|
| StockMockData | `stock_mock.py` | 维护 Mock 股票数据，提供 `get_stock_detail(code)` 接口 |

**设计决策**：Mock 数据内嵌 Python 字典，无需外部文件。数据包含 4 只常用标的 + 1 个默认兜底。

### 2.2 观点相似度计算模块

| 模块 | 文件 | 职责 |
|------|------|------|
| OpinionAnalyzer | `opinion_analyzer.py` | 计算多篇研报间观点的文本相似度，归类共同/差异观点 |

**算法选择**：

| 方案 | 优势 | 劣势 | 决策 |
|------|------|------|------|
| Jaccard 相似度 | 实现简单，无依赖 | 对长文本精度不够 | 排除 |
| TF-IDF + 余弦相似度 | 精度较好 | 需 scikit-learn 依赖 | 排除（教学版轻量优先） |
| 字符级 n-gram 相似度 | 精度适中，零依赖 | 对语义理解有限 | **选用** |

**理由**：教学版不引入重依赖，n-gram 相似度足以处理中文观点短句（10~200字符）。

## 3. ReportParser 扩展

在现有 `report_parser.py` 基础上扩展：

| 扩展项 | 变更 |
|--------|------|
| 股票代码提取 | 新增 `_extract_stock_codes(text)` 方法，多模式正则匹配 |
| 观点原文定位 | `_extract_key_info()` 返回的 key_points 从 `string[]` 改为 `{text, source_text, position}[]` |
| 相似度预计算 | 解析完成后异步调用 `OpinionAnalyzer`，结果存入 extracted_data |

### 3.1 股票代码提取正则

```python
STOCK_CODE_PATTERNS = [
    r'(SH|SZ)\d{6}',           # SH600519, SZ000858
    r'\d{6}\.(SH|SZ)',          # 600519.SH, 000858.SZ
    r'(?:股票代码|证券代码)[：:]\s*(\d{6})',  # 股票代码：600519
    r'(?:代码)\s*(\d{6})',       # 代码 600519
]
```

## 4. 前端架构变更

| 变更 | 说明 |

| 新增 Tab | "知识库" Tab 入口 |

### 4.1 走势图实现

| 方案 | 优势 | 劣势 | 决策 |
|------|------|------|------|
| Chart.js | 功能强大 | 额外依赖 25KB+ | 排除 |
| 原生 SVG | 零依赖 | 手写较繁 | **选用** |
| Canvas 2D | 性能好 | 交互不便 | 排除 |

**理由**：Mock 数据仅 30 个点，SVG 实现简单，无需引入图表库。

## 5. ADR（架构决策记录）

| ADR | 决策 | 核心理由 |
|-----|------|----------|
| ADR-005 | Mock 数据内嵌 Python 字典而非 JSON 文件 | 减少文件 I/O，Mock 数据量小（4 只标的），无需持久化 |
| ADR-006 | 字符级 n-gram 相似度而非 LLM 语义分析 | 教学版零外部依赖，解析阶段不依赖 LLM 可用性 |
| ADR-007 | 研报保留 session_id 字段，知识库通过忽略过滤实现 | 兼容 V1 数据结构，无需数据迁移 |
| ADR-008 | SVG 折线图而非 Chart.js | 教学版不增加前端依赖 |
