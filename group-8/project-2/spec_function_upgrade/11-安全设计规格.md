## 1. 安全目标（新增/变更）

| 安全目标 | 说明 | 对应合规 |
|----------|------|----------|
| Mock 数据不可写 | Mock 股票数据为只读，不接受外部修改 | 数据完整性 |
| 文件删除防误操作 | 删除研报需前端二次确认 + 后端存在性校验 | 操作安全 |
| 沿用基线安全要求 | 数据不出域、最小权限等 | spec_init/11 §1 |

## 2. 接口安全（新增端点）

| 端点 | 安全措施 |
|------|----------|
| `GET /stock/{code}/detail` | 路径参数校验（正则白名单），防止路径穿越 |
| `DELETE /reports/{id}` | UUID 格式校验 + 存在性校验，防止越权删除 |
| `GET /reports?search=` | 搜索关键词长度限制（≤50 字符），防止注入 |

## 3. 文件安全

| 风险 | 措施 |
|------|------|
| 删除操作误删系统文件 | `delete_report` 仅操作 `DATA_DIR/uploads/` 目录内的文件，路径拼接时校验前缀 |
| Mock 数据篡改 | Mock 数据硬编码在 Python 源码中，不读取外部文件 |

## 4. 沿用基线

其余安全设计沿用 `spec_init/11` 规格，包括：认证与授权、数据安全、LLM 安全、审计与日志、STRIDE 威胁模型等。
