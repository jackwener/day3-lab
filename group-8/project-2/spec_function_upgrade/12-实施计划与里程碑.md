## 4. 依赖与风险

**依赖链**：S1 解析增强 → S2 对比优化 → S3 智能对比 → S4 知识库收口

| 风险 | 影响 | 应对 |
|------|------|------|
| 股票代码正则覆盖不全 | 部分研报提取不到代码 | 持续补充正则 + 默认 Mock 兜底 |
| 观点相似度计算不准确 | 共同/差异观点分组不合理 | 可调节阈值 + 用户反馈迭代 |
| V1 数据兼容性问题 | 旧研报展示异常 | 惰性兼容转换 + 全量回归测试 |
