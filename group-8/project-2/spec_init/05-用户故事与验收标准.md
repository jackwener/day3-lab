> **本文只做一件事**：按用户能理解的子场景拆成多条 **User Story**，并为每条写清 **REQ-ID**、**验收标准（AC）**。

## 字段说明 — 每条 UserStory 必须包含以下字段

| 字段 | 填写说明 | 数据来源 ← | 流向下游 → |
|------|----------|------------|-----------|
| **需求编号** | 唯一编号，如 REQ-M1QA-001 | ← `02` 采集编号 | → `14` 追踪矩阵首列 |
| **故事** | 作为【角色】，我希望【行为】，以便【价值】 | ← `04` PRD 场景拆解 | → `06` FSD 功能点 |
| **优先级** | P0（必须）/ P1（应该）/ P2（可选） | ← `03` §4 成功标准 | → `12` 里程碑排期 |
| **来源** | 对应 03/04 哪一条需求 | ← `03` 范围 · `04` 场景 | |
| **前置条件** | 触发该故事的前提状态 | ← `04` 用户流程 | → `13` 测试前置 |
| **功能对齐** | 对应功能规格 + 非功能约束 | | → `06` FSD · `07` NFR |
| **设计对齐** | 对应架构、接口、数据、安全 | | → `08` 架构 · `09` API · `10` Data · `11` 安全 |
| **验证对齐** | 对应测试用例 + 追踪矩阵行 | | → `13` TC · `14` 追踪矩阵行 |
| **验收标准** | AC，每条可独立验证 | ← 故事 + `07` NFR | → `13` 测试用例依据 |

## US-001（P0）会话管理

| 字段 | 内容 |
|------|------|
| **需求编号** | REQ-M1QA-001 |
| **故事** |作为投研分析师，我希望创建、查看、删除问答会话，以便分类管理不同标的 / 研报的问答内容 |
| **优先级** | P0 |
| **来源** | ← 03 §3 范围 / 04 SC-01 |
| **前置条件** | 用户已打开系统页面 |
| **功能对齐** | → 06 §3 Sidebar 会话管理 · 07 §2.2 会话管理延迟 <500ms |
| **设计对齐** | → 08 §2 分层架构 · 09 §4-§6 /sessions API · 10 §3 Session 实体 · 11 §4 CORS |
| **验证对齐** | → 13 TC-M01-020~025 · 14 第 1 行 |

| 验收标准 | 描述（每条可独立测试） |
|----------|----------------------|
| AC-001-01 | 点击"+ 新建"按钮，系统创建新会话并自动选中，标题默认"新会话" |
| AC-001-02 | 会话列表显示所有已创建会话，包含标题和问答次数 |
| AC-001-03 | 点击 × 按钮并确认后，会话及关联问答记录被级联删除 |

## US-002（P0）问答提交

| 字段 | 内容 |
|------|------|
| **需求编号** | REQ-M1QA-002 |
| **故事** | 作为投研分析师，我希望在会话中输入自然语言问题并获得 AI 回答，以便快速获取投研信息 |
| **优先级** | P0 |
| **来源** | ← 03 §3 / 04 SC-01 |
| **前置条件** | 已创建并选中一个会话 |

| **设计对齐** | → 08 §4 三级降级 · 09 §3 POST /ask · 10 §4 QARecord · 11 §4 CORS |

## US-004（P0）研报上传与解析

| 字段 | 内容 |
|------|------|
| **需求编号** | REQ-M1QA-004 |
| **故事** | 作为投研分析师，我希望上传 PDF/HTML 研报后系统自动提取评级、目标价、核心观点等关键信息，以便快速获取研报核心要点而无需逐页阅读 |
| **优先级** | P0 |
| **来源** | ← 03 §3 范围 / 04 SC-02 |
| **前置条件** | 已创建并选中一个会话 |
| **功能对齐** | → 06 §7 研报上传区 · 06 §8 关键信息展示 · 07 §1 研报解析 SLO |
| **设计对齐** | → 08 §4 ReportParser · 09 POST /reports/upload · 10 Report 实体 |
| **验证对齐** | → 13 TC-M01-070~075 · 14 第 4 行 |

| 验收标准 | 描述（每条可独立测试） |
|----------|----------------------|
| AC-004-01 | 支持上传 PDF 和 HTML 格式文件，文件大小 ≤50MB |
| AC-004-02 | 上传后 60 秒内完成解析并展示评级、目标价、核心观点 |
| AC-004-03 | 解析结果关联到当前会话，可在研报列表中查看 |
| AC-004-04 | 文件格式不支持或解析失败时显示友好错误提示 |
