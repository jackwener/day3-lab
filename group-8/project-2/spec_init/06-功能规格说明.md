## 1. 页面总体布局

> 画出你的应用的页面结构（ASCII / 手绘均可）。SPA 通常分：Header + Sidebar + Main + Input Area。

**示例 — 布局结构**：

```
┌──────────────────────────────────────────┐
│  header: 标题 + [能力状态芯片]             │
├────────────┬─────────────────────────────┤
│  sidebar   │  main-content（三态渲染）     │
│  历史会话   │  A) 空状态                    │
│  [+新建]   │  B) 常见问题网格              │
│  session1  │  C) 对话历史列表              │
│  session2  │                              │
│            │  input-area: textarea + 发送  │
└────────────┴─────────────────────────────┘
```

```
┌──────────────────────────────────────────┐
│  header: “投研问答助手” + [能力状态芯片]       │
├────────────┬─────────────────────────────┤
│  sidebar   │  main-content（三态渲染）        │
│  历史会话   │  A) 空状态：“请创建或选择会话”     │
│  [+新建]   │  B) 常见问题网格（可点击快捷提问） │
│  session1  │  C) 对话历史列表（卡片式）       │
│  session2  │                              │
│  session3  │  input-area:                  │
│            │    textarea + 发送按钮 + 清空  │
└────────────┴─────────────────────────────┘
```

- **Header**：左侧应用标题“投研问答助手”，右侧能力状态芯片（CoPaw / 百炼 / 离线演示）
- **Sidebar**：会话列表 + “+ 新建”按钮，每条显示标题与删除按钮
- **Main**：三态渲染（空状态 / 常见问题 / 对话历史）
- **Input Area**：multiline textarea + 发送按钮 + 清空按钮

## 3. Sidebar 会话管理

> 对齐 `05` US-001。描述会话列表的增删查交互。

| 功能 | 触发 | API 调用 | 行为 |
|------|------|----------|------|
| 加载列表 | 页面渲染 | `GET /sessions` | 渲染会话列表 + 默认选中第一个 |
| 新建会话 | 点击"+ 新建" | `POST /sessions` | 插入列表头部 + 自动选中 |
| 删除会话 | 点击 × | `DELETE /sessions/<id>` | 确认弹窗 → 从列表移除 |
| 选中会话 | 点击会话条目 | `GET /sessions/<id>/records` | 设置 `currentSession`，加载该会话问答记录 → Main 切换到对话历史或常见问题状态 |

## 4. Main 内容区（三态渲染）

> 对齐 `05` US-002（问答提交）、US-003（历史记录）。描述三种条件下显示什么。

## 6. 错误处理

| 后端 `error.code` | HTTP | 前端展示 |
|--------------------|------|----------|
| `EMPTY_QUERY` | 400 | 错误提示："请输入问题" |
| `INVALID_QUERY` | 400 | 错误提示："问题过长" |
| `SESSION_NOT_FOUND` | 404 | 错误提示：“会话不存在”，自动刷新会话列表 |
| `INVALID_SESSION_ID` | 400 | 错误提示：“会话 ID 格式错误” |
| 网络异常 / 5xx | 500 | 错误提示：“服务异常，请稍后重试” |

## 9. 研报上传区

> 对齐 `05` US-004。描述研报上传的 UI 规格与交互流程。

### 9.1 上传入口

| 元素 | 位置 | 说明 |
|------|------|------|
| 上传研报按钮 | Main 内容区工具栏 | 当前会话的工具栏中新增"上传研报"按钮 |

### 9.2 上传面板

点击按钮后弹出上传面板，支持以下交互：

| 特性 | 规格 |
|------|------|
| 触发方式 | 点击按钮弹出模态框 / 支持拖拽文件到面板区域 |
| 支持格式 | PDF（.pdf）、HTML（.html/.htm） |
| 文件大小限制 | ≤50MB |

### 9.3 上传流程

```
选择文件 → 显示上传进度条 → 上传完成自动触发解析 → 显示解析状态
```

| 阶段 | 界面表现 |
|------|----------|
| 文件选择 | 弹出文件选择器，过滤仅显示 .pdf/.html/.htm 文件 |
| 上传中 | 显示进度条（百分比），可取消上传 |
| 解析中 | 进度条完成，显示"解析中..."状态动画 |
| 解析完成 | 自动跳转到关键信息展示（§8），关闭上传面板 |
| 解析失败 | 显示错误提示，保留重新上传选项 |

### 9.4 错误处理

| 错误场景 | 提示文案 |
|----------|----------|
| 文件格式不支持 | "仅支持 PDF 和 HTML 格式" |
| 文件超过 50MB | "文件过大，请上传 50MB 以内的文件" |
| 解析失败 | "研报解析失败，请检查文件格式" |
| 网络异常 | "上传失败，请检查网络后重试" |

## 10. 关键信息展示

### 10.1 展示位置

- **形式**：信息卡片形式展示，多个研报以列表形式排列

### 10.2 信息卡片布局

```
┌─────────────────────────────────────────────┐
│  研报标题（文件名）                              │
│  发布机构 · 发布日期                             │

### 10.3 卡片元素规格

| 元素 | 规格 |
|------|------|
| **顶部信息** | 研报标题（文件名）+ 发布机构 + 发布日期 |

| **目标价卡片** | 突出显示目标价数值，如有当前价则显示对比（涨幅/跌幅） |
| **核心观点列表** | 编号列表展示，每条观点一行，最多显示 5 条 |
| **底部操作** | 重新解析按钮、删除按钮 |

### 10.4 评级芯片颜色映射

| 评级 | 颜色 | 色值参考 |

## 11. 研报对比区

> 对齐 `05` US-005。描述研报对比功能的 UI 规格。

### 11.1 对比入口

| 条件 | 界面表现 |
|------|----------|
| 会话中已解析研报 ≥2 份 | 工具栏显示"对比研报"按钮 |
| 会话中已解析研报 <2 份 | 对比按钮禁用，hover 提示"请至少上传 2 份研报" |

### 11.2 研报选择器

点击"对比研报"按钮后弹出选择面板：

| 特性 | 规格 |
|------|------|
| 选择方式 | 勾选框多选 |
| 最少选择 | 2 份 |
| 最多选择 | 5 份 |
| 默认状态 | 全部未选中，实时显示已选数量（已选 X/5） |
| 确认按钮 | 选择 ≥2 份时可用，点击生成对比表 |

### 11.3 对比表格规格

| 维度 | 规格 |
|------|------|
| **列** | 每份研报一列，表头显示研报文件名 + 发布机构 |
| **行** | 评级、目标价、核心观点、发布日期 |
| **差异高亮** | 不同评级/目标价用不同背景色标注，相同值用默认背景 |

### 11.4 对比表格布局示例

```
┌─────────────┬──────────────┬──────────────┬──────────────┐
│   指标      │ 研报A_中金    │ 研报B_高盛    │ 研报C_摩根    │
├─────────────┼──────────────┼──────────────┼──────────────┤
│   评级      │   [买入]     │   [增持]     │   [买入]     │
│             │  bg-green    │  bg-blue     │  bg-green    │
├─────────────┼──────────────┼──────────────┼──────────────┤
│   目标价    │   ¥188.00    │   ¥175.00    │   ¥190.00    │
│             │  bg-yellow   │  bg-default  │  bg-yellow   │
├─────────────┼──────────────┼──────────────┼──────────────┤
│   发布日期  │  2026-04-10  │  2026-04-08  │  2026-04-12  │
├─────────────┼──────────────┼──────────────┼──────────────┤
│   核心观点  │ 1. 业绩超预期 │ 1. 稳健增长   │ 1. 高增长确定 │

### 11.5 加载与错误状态

| 状态 | 界面表现 |
|------|----------|
| 对比生成中 | 显示加载动画（旋转图标 + "正在生成对比表..."） |
