## 1. 概念模型

```
Session（会话）1 ── * QARecord（问答记录）
   │                      │
   │  session_id (PK)     │  id (PK)
   │  title               │  session_id (FK → Session)
   │  query_count          │  query / answer / llm_used
   │  created_at           │  response_time_ms / answer_source
   └  updated_at           └  timestamp
```

> **核心关系**：一个 Session 可包含零到多条 QARecord。外键通过 `session_id` 字段逻辑引用。

## 2. 存储引擎

| 项 | 说明 |
|----|------|
| 引擎 | JSON 文件（`json` 标准库） |
| 编码 | UTF-8，缩进 2 空格 |
| 读写模式 | RMW（全量读入 → 修改 → 全量写回） |
| 并发安全 | 无锁，不支持并发写入 |
| 文件布局 | `{DATA_DIR}/sessions.json` + `qa_records.json` |

## 3. 实体定义 — Session

| 字段 | 类型 | 必填 | 约束 | 说明 |
|------|------|------|------|------|
| `session_id` | `string` (UUID) | 是 | **PK** | 会话唯一标识 |
| `title` | `string` | 是 | ≤23 字符 | 默认"新会话"，首次问答自动重命名 |
| `created_at` | `string` (ISO-8601) | 是 | UTC+Z | 创建时间 |
| `updated_at` | `string` (ISO-8601) | 是 | UTC+Z | 最后更新时间 |
| `query_count` | `integer` | 是 | ≥ 0 | 累计问答次数 |

## 4. 实体定义 — QARecord

| 字段 | 类型 | 必填 | 约束 | 说明 |
|------|------|------|------|------|
| `id` | `string` | 是 | **PK**，`rec_{ts}` | 基于时间戳生成 |
| `session_id` | `string` | 是 | **FK** → Session | 所属会话 |
| `query` | `string` | 是 | 1–500 字符 | 用户提问原文 |
| `answer` | `string` | 是 | — | LLM/Demo 返回的答案 |
| `llm_used` | `boolean` | 是 | RULE-005 | 是否使用真实 LLM |
| `model` | `string\|null` | 是 | — | 模型标识 |
| `response_time_ms` | `integer` | 是 | SLO < 5000 | 响应耗时（ms） |
| `answer_source` | `string\|null` | 否 | 枚举 | `copaw`\|`bailian`\|`demo` |

## 5. Storage 方法清单

> 列出 Storage 类的全部公开方法。每个方法标注关联的 TC 编号（来自 `13`）。

### 5.1 会话管理

| 方法 | 签名 | 行为 | 关联 TC |
|------|------|------|---------|
| `create_session` | `(session_id, title) → dict` | 创建新会话 | TC-M01-041 |
| `get_sessions` | `() → list` | 返回全部会话 | TC-M01-042 |
| `delete_session` | `(session_id) → None` | 删除 + **级联删除**记录 | TC-M01-043 |
| `update_session` | `(session_id, updates: dict) → dict` | 更新会话字段（如 title、query_count、updated_at） | TC-M01-046 |

### 5.2 问答记录管理

| 方法 | 签名 | 行为 | 关联 TC |
|------|------|------|---------|
| `add_record` | `(session_id, query, answer, ...) → dict` | 写入记录 + 更新 query_count | TC-M01-044 |
| `get_records_by_session` | `(session_id) → list` | 按 session_id 过滤 | TC-M01-045 |
| `delete_records_by_session` | `(session_id) → int` | 删除指定会话的所有记录，返回删除条数 | TC-M01-047 |

## 6. 关键业务逻辑

**示例 — 首次问答自动命名**：

```python
if session["query_count"] == 1:
    session["title"] = query[:20] + ("..." if len(query) > 20 else "")
```

> **规则**：仅首次问答（query_count 从 0 → 1）触发，后续不再自动更名。

| 逻辑 | 触发条件 | 行为 |
|------|----------|------|
| 首次问答自动命名 | `query_count` 从 0 → 1 | 标题 = query 前 20 字 + `...` |
| 级联删除 | 删除 Session | 同步删除所有关联 QARecord |
| updated_at 自动更新 | 每次 add_record 或 update_session | 将 session 的 `updated_at` 置为当前 UTC 时间戳 |
| query_count 累加 | add_record 成功后 | session 的 `query_count` 自增 1 |

## 8. 概念模型扩展

```
Session（会话）1 ── * Report（研报）
   │                      │
   │  session_id (PK)     │  report_id (PK)
   │                      │  session_id (FK → Session)
   │                      │  file_name / file_type / file_size
   │                      │  uploaded_at
   │                      └  extracted_data (JSON)
```

> **核心关系**：一个 Session 可包含零到多条 Report。外键通过 `session_id` 字段逻辑引用。

## 9. 实体定义 — Report

| 字段 | 类型 | 必填 | 约束 | 说明 |
|------|------|------|------|------|
| `report_id` | `string` (UUID) | 是 | **PK** | 研报唯一标识 |
| `session_id` | `string` (UUID) | 是 | **FK** → Session | 所属会话 |
| `file_name` | `string` | 是 | ≤255 字符 | 原始文件名 |
| `file_type` | `string` | 是 | `pdf` \| `html` | 文件格式 |
| `file_size` | `integer` | 是 | ≤50MB (52428800 bytes) | 文件大小（字节） |
| `file_path` | `string` | 是 | — | 文件存储路径（相对于 DATA_DIR） |
| `uploaded_at` | `string` (ISO-8601) | 是 | UTC+Z | 上传时间 |
| `extracted_data` | `object` \| `null` | 是 | — | 解析提取结果（解析失败时为 null） |

**extracted_data 子字段**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `rating` | `string` \| `null` | 评级（买入/增持/中性/减持/卖出） |
| `target_price` | `string` \| `null` | 目标价 |
| `core_opinions` | `string[]` | 核心观点列表 |
| `institution` | `string` \| `null` | 发布机构 |
| `publish_date` | `string` \| `null` | 发布日期（ISO-8601） |

## 10. Report 存储规格

| 项 | 规格 |
|----|------|
| 元数据文件 | `{DATA_DIR}/reports.json` |
| 原始文件目录 | `{DATA_DIR}/reports/` |
| 文件命名 | `{report_id}.{ext}`（如 `550e8400...pdf`） |
| 编码 | UTF-8，缩进 2 空格 |
| 读写模式 | RMW（全量读入 → 修改 → 全量写回） |

## 11. Report Storage 方法清单

| 方法 | 签名 | 行为 | 关联 TC |
|------|------|------|---------|
| `create_report` | `(report_id, session_id, file_name, file_type, file_size, file_path) → dict` | 创建研报元数据记录，extracted_data 初始为 null | TC-M01-070 |
| `update_report_extracted` | `(report_id, extracted_data) → dict` | 更新解析结果 | TC-M01-071 |
| `get_reports` | `(session_id=None) → list` | 获取研报列表，可按会话过滤 | TC-M01-072 |
| `get_report` | `(report_id) → dict \| None` | 获取单个研报详情 | TC-M01-073 |
| `delete_report` | `(report_id) → None` | 删除研报元数据 + 原始文件 | TC-M01-074 |
| `delete_reports_by_session` | `(session_id) → int` | 删除指定会话的全部研报，返回删除条数 | TC-M01-075 |

## 12. 研报相关业务逻辑

| 逻辑 | 触发条件 | 行为 |
|------|----------|------|
| 上传后自动解析 | `create_report` 后 | 调用 ReportParser 解析文件，成功则 `update_report_extracted` |
| 会话级联删除扩展 | `delete_session` 时 | 在已有级联删除 QARecord 基础上，追加调用 `delete_reports_by_session` |
| 研报删除清理 | `delete_report` 时 | 同时删除 `{DATA_DIR}/reports/{report_id}.{ext}` 原始文件 |
