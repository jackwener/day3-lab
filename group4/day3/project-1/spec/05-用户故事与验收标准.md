## US-001（P0）会话管理

| 字段 | 内容 |
|------|------|
| **需求编号** | REQ-M1QA-001 |
| **故事** | 作为投研分析师，我希望创建、选择、删除会话，以便组织不同主题的问答记录 |
| **优先级** | P0 |
| **来源** | ← 04 SC-07 |
| **代码对齐** | `agent_bp.py` — POST/GET/DELETE /sessions · `storage.py` — 会话 CRUD + 软删除 |

| 验收标准 | 描述 |
|----------|------|
| AC-001-01 | `POST /sessions` → 201，返回含 session_id、title、created_at、query_count=0 |
| AC-001-02 | `GET /sessions` → 200，返回 sessions 数组（仅 status=active），按 created_at 倒序 |
| AC-001-03 | `DELETE /sessions/<id>` 执行**软删除**（status→deleted），返回 deleted_at 时间戳 |
| AC-001-04 | 删除后会话不出现在列表中，对已删除会话提交问答 **MUST** 返回 SESSION_NOT_FOUND |
| AC-001-05 | 首次问答时会话标题自动更新为 query 前 20 字符 + "..."（`storage.py` add_record） |

## US-002（P0）三级降级问答

| 字段 | 内容 |
|------|------|
| **需求编号** | REQ-M1QA-002 |
| **故事** | 作为投研分析师，我希望提问后获得专业回答，即使外部 LLM 不可用也能得到演示回复 |
| **优先级** | P0 |
| **来源** | ← 04 SC-05 |
| **代码对齐** | `agent.py` — ask() · `copaw_bridge.py` · `bailian_qa.py` |

| 验收标准 | 描述 |
|----------|------|
| AC-002-01 | `POST /ask` 成功 → 200，含 answer、llm_used(bool)、model、response_time_ms、answer_source、traceId |
| AC-002-02 | 降级链 CoPaw → 百炼 → Demo **不可跳级**，每级失败静默降级到下一级 |
| AC-002-03 | CoPaw 不可用时降级到百炼，answer_source=bailian |
| AC-002-04 | 百炼不可用时降级到 Demo，answer_source=demo，llm_used=false |
| AC-002-05 | Demo 模式始终可用，无外部依赖 |
| AC-002-06 | query 为空 → 400 `EMPTY_QUERY`；query > 500 字符 → 400 `INVALID_QUERY` |
| AC-002-07 | 支持 system_prompt 和 context 可选参数（用于自定义智能体和研报追问） |

## US-003（P0）研报解析

| 字段 | 内容 |
|------|------|
| **需求编号** | REQ-M1QA-003 |
| **故事** | 作为投研分析师，我希望上传一份研报后系统自动提取评级、目标价等关键信息，以结构化卡片展示 |
| **优先级** | P0 |
| **来源** | ← 04 SC-02 |
| **代码对齐** | `agent_bp.py` — POST /parse-report · `report_parser.py` — extract_text() + parse_single() |

| 验收标准 | 描述 |
|----------|------|
| AC-003-01 | `POST /parse-report` 支持 PDF（pdfplumber）、Word（python-docx）、HTML（BeautifulSoup） |
| AC-003-02 | 单文件 ≤ 50MB，超大返回错误 |
| AC-003-03 | 解析结果 **MUST** 含：title、institution、publish_date、rating、target_price、financial_forecasts、risks |
| AC-003-04 | 前端以 `ParseCard` 卡片渲染解析结果 |
| AC-003-05 | LLM 不可用时 **MUST** 返回 Demo 解析数据（`report_parser.py` _demo_parse） |
| AC-003-06 | 上传后可基于 text_preview 继续追问（context 传递） |
