## 1. 概念模型

```
Session（会话）1 ── * QARecord（问答记录）
   │                      │
   │  session_id (PK)     │  id (PK)
   │  title               │  session_id (FK → Session)
   │  query_count          │  query / answer / agent_id
   │  status               │  llm_used / model / answer_source
   │  created_at           │  response_time_ms / cited_passages
   └  updated_at           └  created_at

CustomAgent（自定义智能体）
   │
   │  agent_id (PK)
   │  name / description / icon
   │  system_prompt
   │  created_at / updated_at
```

## 2. 存储引擎

| 决策 | 选型 | 理由（对齐 ADR-002） |
|------|------|---------------------|
| 引擎 | **JSON 文件** | 零依赖启动，教学门槛最低 |
| 编码 | UTF-8 | `ensure_ascii=False` |
| 缩进 | 2 空格 | `json.dump(indent=2)` |
| 目录 | `backend/data/`（可通过 `DATA_DIR` 环境变量覆盖） | `storage.py` 构造函数 |
| 模式 | 单例 `Storage._instance` | 全局唯一实例 |

### 2.1 存储文件清单

| 文件 | 内容 | 结构 |
|------|------|------|
| `data/sessions.json` | 会话列表 | JSON Array of Session |
| `data/qa_records.json` | 问答记录列表 | JSON Array of QARecord |
| `data/custom_agents.json` | 自定义智能体列表 | JSON Array of CustomAgent |

### 2.2 读写模式

- **RMW（Read-Modify-Write）**：读取整个 JSON 文件 → 修改内存数据 → 全量写回
- JSON 解析异常时返回空列表 + `logging.error` 日志
- 文件不存在时自动创建（写入 `[]`）

## 3. 实体定义

### 3.1 Session（会话）

| 字段 | 类型 | 约束 | 生成方式 | 说明 |
|------|------|------|----------|------|
| `session_id` | string | **PK**，32 字符 hex | `uuid.uuid4().hex` | 会话唯一标识 |
| `title` | string | ≤ 100 字符 | 创建时用户指定或默认"新会话" | 首次问答后自动更新为 query 前 20 字符 + "..." |
| `created_at` | string | ISO-8601 UTC | `datetime.utcnow().isoformat()+"Z"` | 创建时间 |
| `updated_at` | string | ISO-8601 UTC | 同上 | 最后更新时间（每次 add_record 时更新） |
| `query_count` | integer | ≥ 0 | 初始 0 | 累计问答数（每次 add_record +1） |
| `status` | string | 枚举：`active` / `deleted` | 初始 `active` | 软删除标记 |

**示例**：
```json
{
  "session_id": "a1b2c3d4e5f6a7b8a1b2c3d4e5f6a7b8",
  "title": "贵州茅台投资分析...",
  "created_at": "2026-04-15T10:30:00Z",
  "updated_at": "2026-04-15T10:35:00Z",
  "query_count": 3,
  "status": "active"
}
```

### 3.2 QARecord（问答记录）

| 字段 | 类型 | 约束 | 生成方式 | 说明 |
|------|------|------|----------|------|
| `id` | string | **PK** | `rec_{timestamp_ms}_{random_4digits}` | 含时间戳，便于排序和调试 |
| `session_id` | string | **FK → Session** | 请求传入 | 关联会话 |
| `query` | string | 1–500 字符 | 用户输入 | 用户提问 |
| `answer` | string | — | LLM / Demo 生成 | AI 回答 |
| `llm_used` | boolean | — | 编排层决定 | 是否使用真实 LLM |
| `model` | string / null | — | 编排层决定 | 模型标识（copaw / qwen-turbo / null） |
| `response_time_ms` | integer | ≥ 0 | 计时器 | 端到端响应耗时 |
| `answer_source` | string | 枚举：`copaw` / `bailian` / `demo` | 编排层决定 | 回答来源标识 |
| `cited_passages` | array / null | — | CoPaw 返回 | 引用段落 `[{text, page, source_file}]` |
| `created_at` | string | ISO-8601 UTC | 自动生成 | 创建时间 |

**示例**：
```json
{
  "id": "rec_1713234567890_4321",
  "session_id": "a1b2c3d4e5f6a7b8a1b2c3d4e5f6a7b8",
  "query": "贵州茅台的目标价是多少？",
  "answer": "根据最新研报...",
  "llm_used": true,
  "model": "qwen-turbo",
  "response_time_ms": 2300,
  "answer_source": "bailian",
  "cited_passages": null,
  "created_at": "2026-04-15T10:35:00Z"
}
```

### 3.3 CustomAgent（自定义智能体）

| 字段 | 类型 | 约束 | 生成方式 | 说明 |
|------|------|------|----------|------|
| `agent_id` | string | **PK**，32 字符 hex | `uuid.uuid4().hex` | 智能体唯一标识 |
| `name` | string | **必填**，≤ 20 字符 | 用户输入 | 显示名称 |
| `description` | string | 选填，≤ 200 字符 | 用户输入 | 卡片描述 |
| `icon` | string | 选填，≤ 10 字符 | 用户选择，默认 🤖 | Emoji 图标 |
| `system_prompt` | string | **必填**，≤ 5000 字符 | 用户输入 | 角色定义提示词 |
| `created_at` | string | ISO-8601 UTC | 自动生成 | 创建时间 |
| `updated_at` | string | ISO-8601 UTC | 自动生成 | 最后更新时间 |

**示例**：
```json
{
  "agent_id": "b2c3d4e5f6a7b8c9b2c3d4e5f6a7b8c9",
  "name": "价值投资分析师",
  "description": "擅长基本面分析和价值投资策略",
  "icon": "💎",
  "system_prompt": "你是一位价值投资专家...",
  "created_at": "2026-04-15T09:00:00Z",
  "updated_at": "2026-04-15T09:00:00Z"
}
```

### 3.4 ParsedReport（研报解析结果 — 非持久化）

> 研报解析结果**不存储到 JSON 文件**，仅在 API 响应中返回，前端通过 `reportCtx` 状态缓存用于追问。

| 字段 | 类型 | 说明 |
|------|------|------|
| `title` | string | 研报标题 |
| `institution` | string | 发布机构/券商 |
| `publish_date` | string | YYYY-MM-DD |
| `target_company` | string | 目标公司名称 |
| `stock_code` | string | 股票代码 |
| `rating` | string | 买入/增持/中性/减持/卖出 |
| `target_price` | string | 目标价格 |
| `current_price` | string | 报告时股价 |
| `summary` | string | 核心观点摘要（≤300 字） |
| `financial_forecasts` | object | `{revenue_growth_2024, revenue_growth_2025, net_profit_2024, net_profit_2025, pe_2024, pe_2025, pb}` |
| `risks` | string[] | 风险提示列表 |

## 4. Storage 类方法清单（对齐 storage.py）

### 4.1 会话管理

| 方法 | 签名 | 返回 | 说明 |
|------|------|------|------|
| `create_session` | `(title="新会话")` | Session dict | 生成 UUID session_id，query_count=0，status=active |
| `get_sessions` | `()` | Session[] | 仅返回 status=active，按 created_at 倒序 |
| `get_session` | `(session_id)` | Session / None | 按 session_id 查找（不过滤 status） |
| `delete_session` | `(session_id)` | dict / None | 软删除：status→deleted，添加 deleted_at；**级联删除**关联的 QARecord |

### 4.2 问答记录

| 方法 | 签名 | 返回 | 说明 |
|------|------|------|------|
| `add_record` | `(session_id, query, answer, llm_used, model, response_time_ms, answer_source, cited_passages)` | QARecord dict | 生成 rec_id；更新会话 query_count +1、updated_at；首条记录时自动更新会话 title |
| `get_records` | `(session_id)` | QARecord[] | 按 created_at 正序返回 |

### 4.3 自定义智能体

| 方法 | 签名 | 返回 | 说明 |
|------|------|------|------|
| `get_custom_agents` | `()` | Agent[] | 返回全部自定义智能体 |
| `create_custom_agent` | `(name, description, icon, system_prompt)` | Agent dict | 生成 UUID agent_id |
| `update_custom_agent` | `(agent_id, **kwargs)` | Agent / None | 仅更新传入的字段 + updated_at |
| `delete_custom_agent` | `(agent_id)` | dict / None | 硬删除（从 JSON 数组中移除） |

### 4.4 内部工具方法

| 方法 | 说明 |
|------|------|
| `_load(filename)` | 读取 JSON 文件，异常时返回 [] + ERROR 日志 |
| `_save(filename, data)` | 全量写回 JSON 文件，UTF-8 编码，2 空格缩进 |

## 5. 数据完整性约束

| 约束 | 实现方式 |
|------|----------|
| Session PK 唯一 | `uuid.uuid4().hex` 碰撞概率可忽略 |
| QARecord → Session FK | add_record 前校验 session_id 对应的会话存在且 active |
| 级联删除 | delete_session 时同步删除关联的 qa_records |
| 首条记录自动命名 | add_record 中 `query_count == 0` 时更新 session title |
| JSON 损坏恢复 | _load 异常 → 返回 `[]`，不中断服务 |
| 文件不存在 | _save 自动创建，_load 返回 `[]` |
