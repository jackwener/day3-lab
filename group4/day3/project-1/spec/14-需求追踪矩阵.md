## 8. 变更影响分析指引

> **当需求变更时，按以下路径排查影响范围**：

```
REQ 变更
  ↓ 查 §2 主追踪矩阵
US 受影响
  ↓ 查 §4 US→API 映射
API 端点受影响
  ↓ 查 §5 代码文件映射
代码文件需修改
  ↓ 查 §2 测试用例列
TC 需更新/补充
```

**示例**：若 REQ-003 研报解析新增 Excel 格式支持：
1. §2 → US-003 受影响
2. §4 → POST /parse-report 端点需改
3. §5 → `report_parser.py` + `agent_bp.py` 需改
4. §2 → TC-020~025 需新增 Excel 用例
