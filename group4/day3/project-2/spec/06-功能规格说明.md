## 2. 详细功能规格

### 2.1 入口页模块

**功能描述**：应用首页，营造仪式感氛围，引导用户开始占卜。

**交互流程**：
1. 页面加载，显示背景动画（星空/粒子效果）
2. 大标题从上方淡入（"Vibe Oracle"或"命运启示"）
3. 副标题延迟 0.5s 淡入（"宇宙正在等你"等）
4. 开始按钮延迟 1s 淡入并轻微脉动
5. 用户点击按钮，触发页面切换

**输入约束**：

| 字段 | 类型 | 约束 | 错误提示 |
|------|------|------|----------|
| 开始按钮 | 点击事件 | 首次点击后禁用 3 秒防止重复 | 无 |

**输出规格**：

| 字段 | 类型 | 说明 |
|------|------|------|
| pageState | string | 切换到 'ritual' 状态 |

**视觉规格**：
- 背景：深色渐变（#0a0a1a → #1a1a3e）
- 标题：白色，字体大小 48px（桌面）/ 32px（移动）
- 按钮：紫色渐变背景，圆角 8px，hover 发光效果

---

### 2.2 仪式动画模块

**功能描述**：2秒内完成从入口到卡牌祭坛的过渡动画。

**交互流程**：
1. 入口页淡出（300ms）
2. 星点汇聚：随机分布的光点向中心聚集（600ms）
3. 扫描线：水平光线从上至下扫描（400ms）
4. 信号锁定：中心出现锁定图标+波纹效果（300ms）
5. 卡牌祭坛显现：9张卡牌从中心向外展开（400ms）

**动画时序**：

| 阶段 | 时长 | 缓动函数 |
|------|------|----------|
| 入口淡出 | 300ms | ease-out |
| 星点汇聚 | 600ms | ease-in-out |
| 扫描线 | 400ms | linear |
| 信号锁定 | 300ms | ease-out |
| 祭坛展开 | 400ms | cubic-bezier(0.34, 1.56, 0.64, 1) |
| **总计** | **≈2s** | - |

**降级方案**：
- `prefers-reduced-motion`：简化动画，直接切换
- 低端设备：检测帧率，低于 20fps 时自动降级

---

### 2.3 卡牌祭坛模块

**功能描述**：9张卡牌3D透视展示，支持悬停和点击交互。

**交互流程**：
1. 9张卡牌以3x3网格或弧形排列
2. 每张卡牌有3D透视效果（rotateX/rotateY）
3. 桌面端：鼠标悬停时卡牌上浮+发光
4. 移动端：点击选中，高亮显示
5. 已选卡牌从祭坛移除或标记为已选

**3D布局参数**：

| 参数 | 桌面端 | 移动端 |
|------|--------|--------|
| 卡牌尺寸 | 120x180px | 80x120px |
| 排列方式 | 弧形（perspective: 1000px） | 3x3 网格 |
| 间距 | 20px | 10px |
| 透视角度 | rotateY(-15deg ~ 15deg) | 无 |

**卡背设计**：
- 统一卡背图案：神秘符号/星空纹理
- 边框：金色/紫色发光边框
- 材质感：轻微纹理叠加

**状态管理**：

| 状态 | 视觉表现 | 交互 |
|------|----------|------|
| 默认 | 卡背朝上，3D透视 | 可悬停/点击 |
| 悬停 | 上浮 10px，发光增强 | - |
| 选中 | 翻转至正面，移至屏幕中央 | 不可再次选择 |
| 已抽 | 从祭坛消失或变灰 | 不可选择 |

---

### 2.4 抽卡流程模块

**功能描述**：控制三阶段抽卡的顺序和状态流转。

**状态机**：

```
[INIT] → 等待选择第1张卡
  ↓ 选择第1张卡
[STATE_REVEALED] → 显示状态卡，等待选择第2张
  ↓ 选择第2张卡
[DESIRE_REVEALED] → 显示欲望卡，等待选择第3张
  ↓ 选择第3张卡
[RESULT_REVEALED] → 显示结果卡，进入改命/结局
```

**卡牌翻转动画**：

| 阶段 | 时长 | 效果 |
|------|------|------|
| 卡牌从祭坛飞出 | 300ms | scale(1) → scale(1.2)，移至中央 |
| 翻转至正面 | 500ms | rotateY(0) → rotateY(180)，背面隐藏 |
| 内容展示 | 400ms | 文字淡入 |
| 停留时间 | 2000ms | 用户阅读时间 |
| 归位/下一卡 | 300ms | 移至侧边或淡出 |

**卡牌数据结构**：

```typescript
interface Card {
  id: string;
  type: 'state' | 'desire' | 'result';
  title: string;
  content: string;
  theme: 'light' | 'dark' | 'chaos';
}
```

**卡池配置**：

| 类型 | 数量 | 示例 |
|------|------|------|
| 状态卡 | 3张 | "深夜哲学家", "代码战士", "摸鱼大师" |
| 欲望卡 | 3张 | "想要被理解", "渴望突破", "只想躺平" |
| 结果卡 | 3张 | "意外之喜", "平稳过渡", "惊天逆转" |

### 2.5 改命选择模块（P1）

**功能描述**：3张卡揭示后，提供接受命运或尝试改命的选择。

**交互流程**：
1. 第3张卡揭示完成后，显示选择面板
2. 面板从底部滑入，半透明背景
3. 两个选项并排展示：
   - "接受命运"：默认选项，直接进入结局
   - "尝试改命"：重新抽取第3张卡或调整结局
4. 用户选择后，面板滑出，进入对应流程

**改命逻辑**：

| 选择 | 效果 |
|------|------|
| 接受命运 | 直接使用当前3张卡生成结局 |
| 尝试改命 | 从剩余结果卡中重新随机一张，或结局文案倾向改变 |

### 2.6 结局生成模块

**功能描述**：根据3张卡组合生成最终结局文案。

**组合规则**：

| 状态卡 | 欲望卡 | 结果卡 | 结局类型 | 主题色 |
|--------|--------|--------|----------|--------|
| 任何 | 任何 | 意外之喜 | 惊喜型 | 金色 #FFD700 |
| 深夜哲学家 | 想要被理解 | 任何 | 共鸣型 | 蓝色 #4A90D9 |
| 代码战士 | 渴望突破 | 惊天逆转 | 逆袭型 | 红色 #E74C3C |
| 摸鱼大师 | 只想躺平 | 平稳过渡 | 佛系型 | 绿色 #2ECC71 |
| 其他组合 | - | - | 通用型 | 紫色 #9B59B6 |

**结局文案模板**：

```
【状态】的你，内心【欲望】，命运将导向【结果】。

最终结局：
[根据组合生成的个性化结局，50-100字]
```

**示例结局**：
- 惊喜型："宇宙给你准备了一个彩蛋，就在下个转角。保持开放，惊喜自来。"
- 共鸣型："有人正在读懂你的沉默。不必解释，同频的人自会相遇。"
- 逆袭型："你的坚持正在发酵。看似停滞的一切，即将破冰。"
- 佛系型："慢即是快，少即是多。你选择的平静，本身就是一种力量。"

### 2.7 人格报告模块

**功能描述**：展示人格标签和5个维度的状态条。

**人格标签生成**：

| 组合特征 | 标签 |
|----------|------|
| 深夜哲学家 + 想要被理解 | "孤独观察者" |
| 代码战士 + 渴望突破 | "破局先锋" |
| 摸鱼大师 + 只想躺平 | "反卷达人" |
| 其他 | 随机从标签池选择 |

**状态条规格**：

| 维度 | 取值范围 | 计算方式 |
|------|----------|----------|
| 运势 | 0-100 | 随机 60-95 |
| 行动力 | 0-100 | 根据状态卡类型 |
| 发疯值 | 0-100 | 随机 30-80 |
| 反内耗指数 | 0-100 | 根据欲望卡类型 |
| 神秘值 | 0-100 | 固定 88（彩蛋） |

**动画效果**：
- 状态条从0动画增长到目标值（1.5s，ease-out）
- 数值实时显示在条右侧
- 颜色渐变：低值红色 → 中值黄色 → 高值绿色

### 2.8 分享卡模块（P1）

**功能描述**：生成适合截图分享的最终结果卡片。

**布局规格**：

| 元素 | 位置 | 样式 |
|------|------|------|
| 标题 | 顶部居中 | "Vibe Oracle · 今日命运" |
| 人格标签 | 标题下方 | 大号字体，主题色背景 |
| 最终结局 | 中部 | 正文，限制3行 |
| 状态条 | 下部 | 简化版，显示数值 |
| 装饰元素 | 四角 | 神秘符号/星图 |
| 二维码（可选） | 右下角 | "扫码体验" |

**截图优化**：
- 背景使用纯色或渐变，避免透明
- 文字对比度 ≥4.5:1
- 整体尺寸：600x800px（适合社交媒体）

---

### 2.9 重置模块

**功能描述**：重置所有状态，开始新一轮占卜。

**重置内容**：

| 数据项 | 重置方式 |
|--------|----------|
| 当前抽卡记录 | 清空数组 |
| 卡牌状态 | 全部恢复为默认 |
| 结局结果 | 清空 |
| 人格报告 | 清空 |
| 页面状态 | 回到 'landing' 或 'altar' |

**交互流程**：
1. 用户点击"再来一次"按钮
2. 显示确认提示（可选，防止误触）
3. 当前页面淡出（300ms）
4. 状态重置
5. 入口页或祭坛页淡入

---

### 2.10 暖场测试模块（P2）

**功能描述**：5道轻量问题，生成结果标签影响命运风格。

**问题示例**：

| 题号 | 问题 | 选项 |
|------|------|------|
| Q1 | 此刻你的能量值？ | 满格 / 一半 / 需要充电 |
| Q2 | 最近一周的关键词？ | 忙碌 / 平静 / 混乱 |
| Q3 | 你更相信？ | 直觉 / 逻辑 / 运气 |
| Q4 | 此刻最想？ | 突破 / 休息 / 连接 |
| Q5 | 用一个词形容自己？ | 火焰 / 水流 / 风 |

**标签计算**：
- 根据选项组合，生成标签如"70%火焰+30%水流"
- 标签轻微影响结局文案的形容词选择

---

### 2.11 图册模块（P2）

**功能描述**：保存和查看历史抽卡结果。

**存储方式**：localStorage，键名 `vibe-oracle-history`

**数据结构**：

```typescript
interface HistoryRecord {
  id: string;
  timestamp: number;
  cards: Card[];
  ending: string;
  personalityTag: string;
  stats: Record<string, number>;
}
```

**展示方式**：
- 网格布局，每卡片显示时间、标签、3张卡缩略图
- 点击可查看详情
- 提供"清空图册"按钮

## 3. 错误处理

| 场景 | error.code | HTTP状态 | 前端展示 |
|------|-----------|----------|----------|
| 本地存储写入失败 | STORAGE_ERROR | 无 | 静默失败，不影响主流程 |
| 动画执行异常 | ANIMATION_ERROR | 无 | 降级为直接显示 |
| 状态异常（如重复抽卡） | STATE_INVALID | 无 | 忽略操作，保持当前状态 |

## 4. 边界条件

| 条件 | 处理方式 |
|------|----------|
| 用户快速连续点击卡牌 | 防抖处理，动画期间忽略点击 |
| 页面刷新 | 当前进度丢失，回到入口页 |
| 浏览器返回 | 根据历史记录回到上一状态 |
| 屏幕旋转（移动端） | 重新计算3D布局参数 |
| localStorage 已满 | 清空最旧记录，或禁用图册功能 |
| 低端设备性能不足 | 自动降级为2D效果 |
