## 1. 架构概览

## 2. 前端分层

| 层 | 职责 | 允许 | 禁止 |
|----|------|------|------|
| Pages | 页面级组件，路由状态对应 | 组合 Components，调用 Hooks | 直接操作 DOM，直接访问 localStorage |
| Components | 可复用 UI 组件 | 接收 props，触发回调 | 管理全局状态，直接访问存储 |
| Hooks | 业务逻辑封装 | 使用 Context，操作 localStorage | 直接渲染 JSX，直接操作 DOM |
| Store | 全局状态管理 | 状态更新，订阅通知 | 副作用操作（API 调用等） |
| Utils | 工具函数 | 纯函数计算 | 副作用，状态依赖 |
| Data | 静态数据 | 导出配置对象 | 运行时修改 |

## 3. 技术选型

| 组件 | 选型 | 版本 | 理由 |
|------|------|------|------|
| 框架 | React | 18.x | 组件化开发，生态成熟 |
| 语言 | TypeScript | 5.x | 类型安全，IDE 友好 |
| 构建 | Vite | 5.x | 快速启动，热更新 |
| 样式 | CSS Modules + CSS Variables | - | 样式隔离，主题切换 |
| 动画 | CSS Animations + Framer Motion | - | 3D 翻转，流畅过渡 |
| 3D 效果 | CSS 3D Transforms | - | 无需 Three.js，性能更好 |
| 图标 | Lucide React | - | 轻量，风格统一 |
| 存储 | localStorage API | - | 简单数据持久化 |

## 4. 降级策略

| 级别 | 触发条件 | 行为 | 实现方式 |
|------|----------|------|----------|
| 1级-完整 | 现代浏览器，良好性能 | 3D 透视，粒子动画，发光效果 | CSS 3D + Canvas 粒子 |
| 2级-简化 | 平板/中端手机 | 简化 3D，减少粒子 | CSS 3D + 减少粒子数 |
| 3级-基础 | 低端设备/省流量 | 2D 翻转，无粒子 | CSS 2D + 静态背景 |
| 4级-最小 | 用户偏好减少动画 | 无动画，即时切换 | prefers-reduced-motion |

**降级检测逻辑**：

```typescript
const detectPerformanceLevel = (): number => {
  const memory = (navigator as any).deviceMemory;
  const cores = navigator.hardwareConcurrency;
  if (memory >= 8 && cores >= 6) return 1;
  if (memory >= 4 && cores >= 4) return 2;
  return 3;
};

const prefersReducedMotion = (): boolean => {
  return window.matchMedia('(prefers-reduced-motion: reduce)').matches;
};
```

## 5. 存储架构

### 5.1 存储引擎

| 数据类型 | 引擎 | 理由 |
|----------|------|------|
| 当前游戏状态 | React Context (内存) | 频繁更新，无需持久化 |
| 历史图册 | localStorage | 会话级持久化，简单轻量 |
| 用户偏好 | localStorage | 主题、动画开关等 |
| 卡牌/结局数据 | 代码内 JSON/TS | 静态配置，构建时确定 |

## 6. 前端架构

### 6.1 状态管理

```typescript
interface GameState {
  phase: 'landing' | 'ritual' | 'altar' | 'revealing' | 'choice' | 'ending' | 'report' | 'share';
  selectedCards: Card[];
  availableCards: Card[];
  currentReveal: number;
  ending: Ending | null;
  personality: Personality | null;
  warmUpResult: WarmUpResult | null;
  history: HistoryRecord[];
}
```

### 6.2 页面状态流转

```
Landing → Ritual → Altar → Revealing (x3) → Choice → Ending → Report → Share → Landing
```
