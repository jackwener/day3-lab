## 1. 安全架构概览

Vibe Oracle 是一个纯前端单页应用，无后端服务，无用户认证，无敏感数据存储。安全风险主要集中在：
- XSS（跨站脚本攻击）
- 本地存储数据完整性
- 第三方依赖安全

```
┌───────────────────────────────────────────────────┐
│                    浏览器沙箱                       │
│  ┌─────────────────────────────────────────────┐  │
│  │            React App (CSP 保护)              │  │
│  │  ┌──────────┐  ┌──────────┐  ┌──────────┐  │  │
│  │  │ 自动转义  │  │ 无 eval  │  │ 无内联JS │  │  │
│  │  │ (React)  │  │ (严格)   │  │ (CSP)    │  │  │
│  │  └──────────┘  └──────────┘  └──────────┘  │  │
│  │                     │                       │  │
│  │  ┌──────────────────┴─────────────────────┐ │  │
│  │  │          localStorage (非敏感数据)       │ │  │
│  │  │  - 历史图册 (JSON, 有完整性校验)        │ │  │
│  │  │  - 用户偏好 (JSON, 有默认值回退)        │ │  │
│  │  └────────────────────────────────────────┘ │  │
│  └─────────────────────────────────────────────┘  │
└───────────────────────────────────────────────────┘
```

## 2. STRIDE 威胁分析

| 威胁类型 | 适用性 | 风险等级 | 分析 | 缓解措施 |
|----------|--------|----------|------|----------|
| **S**poofing（伪造） | 低 | 低 | 无用户认证，无需伪造身份 | N/A |
| **T**ampering（篡改） | 中 | 低 | localStorage 数据可被用户篡改 | JSON Schema 校验 + 默认值回退 |
| **R**epudiation（否认） | 低 | 低 | 无交易行为，无需抗否认 | N/A |
| **I**nformation Disclosure（信息泄露） | 低 | 低 | 无敏感数据，仅存储游戏记录 | 不存储任何 PII |
| **D**enial of Service（拒绝服务） | 中 | 低 | localStorage 写满可导致功能降级 | 存储限额 + FIFO 淘汰 |
| **E**levation of Privilege（提权） | 低 | 低 | 纯前端无后端，无提权路径 | N/A |

## 3. 安全检查清单

### 3.1 XSS 防护

| # | 检查项 | 措施 | 状态 |
|---|--------|------|------|
| S-001 | 使用 React 自动转义 | 所有文本通过 JSX 渲染，不使用 dangerouslySetInnerHTML | ✅ 设计保证 |
| S-002 | 禁止 eval / Function 构造 | ESLint 规则禁止 eval | ✅ 配置 |
| S-003 | 禁止内联事件处理 | 使用 React 事件绑定 | ✅ 框架保证 |
| S-004 | 用户输入校验 | 暖场测试答案仅接受预定义索引 | ✅ 设计保证 |

### 3.2 存储安全

| # | 检查项 | 措施 | 状态 |
|---|--------|------|------|
| S-005 | 不存储敏感数据 | localStorage 仅存游戏记录和偏好 | ✅ 设计保证 |
| S-006 | 数据完整性校验 | 读取时验证 JSON 结构，失败则返回默认值 | ✅ 代码实现 |
| S-007 | 存储限额保护 | 最多 20 条记录，超出 FIFO 淘汰 | ✅ 代码实现 |
| S-008 | 存储异常处理 | try-catch 包裹所有 localStorage 操作 | ✅ 代码实现 |

### 3.3 第三方依赖

| # | 检查项 | 措施 | 状态 |
|---|--------|------|------|
| S-009 | 依赖最小化 | 仅使用 React、Framer Motion、Lucide 等必要依赖 | ✅ 设计保证 |
| S-010 | 依赖版本锁定 | package-lock.json 锁定精确版本 | ✅ 配置 |
| S-011 | 无已知漏洞 | 构建前 npm audit | ✅ CI 集成 |

### 3.4 内容安全

| # | 检查项 | 措施 | 状态 |
|---|--------|------|------|
| S-012 | 静态内容安全 | 卡牌文案为静态配置，非用户生成 | ✅ 设计保证 |
| S-013 | 无外部资源加载 | 无外部 CDN 依赖，所有资源本地打包 | ✅ 构建保证 |

## 4. CSP 配置建议

```
Content-Security-Policy:
  default-src 'self';
  script-src 'self';
  style-src 'self' 'unsafe-inline';
  img-src 'self' data:;
  font-src 'self';
  connect-src 'none';
  frame-src 'none';
  object-src 'none';
  base-uri 'self';
```

> **说明**：`style-src 'unsafe-inline'` 是因为 CSS-in-JS / Framer Motion 需要内联样式。若使用纯 CSS Modules 可移除。

## 5. 数据保护

### 5.1 数据分类

| 数据类型 | 敏感级别 | 存储位置 | 保护措施 |
|----------|----------|----------|----------|
| 卡牌内容 | 公开 | 代码内 | 无需加密 |
| 游戏状态 | 非敏感 | 内存 | 页面关闭自动清除 |
| 历史记录 | 非敏感 | localStorage | 用户可主动清除 |
| 用户偏好 | 非敏感 | localStorage | 用户可主动清除 |

### 5.2 数据生命周期

| 阶段 | 操作 | 说明 |
|------|------|------|
| 创建 | 用户抽卡完成 | 记录写入 localStorage |
| 读取 | 查看图册 | 从 localStorage 解析 |
| 更新 | 新增记录 | 追加到数组，FIFO 淘汰 |
| 删除 | 用户清除/超过 20 条 | 从 localStorage 移除 |

## 6. 安全测试要求

| # | 测试项 | 方法 | 预期结果 |
|---|--------|------|----------|
| ST-001 | XSS 注入 | 构造特殊字符作为输入 | React 自动转义，无脚本执行 |
| ST-002 | localStorage 篡改 | 手动修改存储数据 | 应用正常降级，使用默认值 |
| ST-003 | localStorage 清空 | 清除浏览器存储 | 应用正常启动，历史记录为空 |
| ST-004 | CSP 违规 | 注入外部脚本标签 | 被 CSP 拦截 |
| ST-005 | 存储溢出 | 填满 localStorage | 触发 FIFO 淘汰或存储降级 |
