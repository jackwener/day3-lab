## 6. 风险与应对

| 风险 | 概率 | 影响 | 应对 |
|------|------|------|------|
| 3D CSS 效果在低端设备卡顿 | 高 | 中 | 降级策略预置，先实现 2D 版本 |
| 结局组合文案不够有趣 | 中 | 低 | 先用占位文案，后期打磨 |
| 仪式动画过于复杂 | 中 | 中 | CSS 动画优先，Canvas 粒子可选 |
| Framer Motion 包体积过大 | 低 | 低 | 按需引入，tree-shaking |
